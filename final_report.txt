12. Validation Rules
================================================================================

Semantic validator extensions (validateStructuralDesignModel +
validateBridgeSuperstructureDesignDocument):

  BSDD_ENTITY_ID_INVALID — invalid UUID on model/entity stable IDs
  BSDD_DUPLICATE_ENTITY_ID — document-wide duplicate stable ID scan
  BSDD_DANGLING_REFERENCE — non-null refs must resolve; null skips check
  BSDD_ENTITY_REVISION_ID_INVALID — entityRevisionId must be positive integer
  BSDD_ENTITY_KIND_MISMATCH — entityKind must match collection membership
  BSDD_NULL_BINDING_VIOLATION — geometryRef/analysisMapping bindingStatus vs null refs
  BSDD_NON_COMPOSITE_ASSERTION_INVALID — compositeAction must be false
  BSDD_COMPOSITE_CONNECTOR_FORBIDDEN — compositeShearConnector / slabGirderConnector rejected
  BSDD_DECK_ANCHORAGE_ROLE_INVALID — DeckAnchorage anchorageRole non-composite enum only
  BSDD_ADOPTION_DESIGN_STATUS_CONTRADICTION — check-result vs adoption consistency
  BSDD_DESIGN_STATUS_NOT_AUTHORIZED_FAIL_CLOSED — OK/NG/WARNING/ERROR blocked without authority
  BSDD_DESIGN_STATUS_INVALID — unsupported designStatus value

Fail-closed:
  - NOT_AUTHORIZED / INCOMPLETE entities do not implicitly yield OK
  - Check-result statuses blocked without numeric authority and ADOPTED adoption
  - Non-null analysisMemberRefId rejected (empty analysis-member registry in AP-DX-01)
