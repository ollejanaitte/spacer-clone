2. Test / Golden / Negative Path設計（FROZEN）
====================================================================

- old Apollo → SuperstructureDocument mapping（全field・単位・nullability）
- old Substructure → SubstructureDocument mapping
- legacy import（上部工JSON/下部工JSON→PDC・conflict・backup・**import idempotence**）
- PDC Save / restart / .spacerproj round-trip
- dual-write不存在（PDC→legacy export禁止test）
- GeometrySnapshot deterministic（同一入力→同一fingerprint）
- placementSnapshot deterministic + DERIVED（**deep-trim・restore順序固定**・再計算）
- stale / invalid（Road/Bridge/Super/Sub変更→downstream・line/support削除→INVALID）
- UI validation・canonical commit（**原子性・revision競合・autosave失敗時UI rollback**）
- feature flag（ON/OFF・rollback）
- legacy conflict・invalid schema・missing/deleted support・import failure
- NOT_AUTHORIZED action attempt（HOLD領域操作→拒否）
- **正規化配列の一意性・参照整合・zOverride回帰（placement adapterがengineへ渡すか）**
- Golden/reference: 原則変更禁止（変更時は理由記録）
