================================================================================
統合設計 Phase 3-A  3-00 Coordinate / Unit / Origin 責任境界Freeze
================================================================================
確定日: 2026-08-11

--------------------------------------------------------------------------------
1. 目的
--------------------------------------------------------------------------------
Phase 2 Road CIMとTerrainを同一Project座標系へ重ねられる契約を確定し、
大きな公共座標をそのままThree.jsへ投入して精度問題を起こさないための
Project Origin / Local Origin責任を明文化する。

--------------------------------------------------------------------------------
2. Coordinate System / Axis Convention
--------------------------------------------------------------------------------
- domain XYZ: X=道路軸方向 / Y=横断方向 / Z=標高（Phase 2 Road CIMと同一規約）
- Three.js表示変換（ADAPT・表示責任）:
    three.x = domain.x
    three.y = domain.z  (height)
    three.z = -domain.y (transverse, mirrored so +right stays +right)
  ※ 既存threeCoords.tsのdomainToThreeを踏襲
- Viewer変換は表示責任。Terrain正本そのものを書き換えない。

--------------------------------------------------------------------------------
3. Global / Project / Local Coordinate
--------------------------------------------------------------------------------
- global coordinate : 測量座標（JGD2011等）に相当する大座標
- project coordinate: Project Data Core内で扱う座標（Project Originを基準にした相対座標）
- local rendering coordinate: Viewer描画用の座標（Local Origin基準）

--------------------------------------------------------------------------------
4. Project Origin / Local Origin
--------------------------------------------------------------------------------
- Project Origin : Project Data Core内の正本座標基準。global→project変換の起点。
- Local Origin   : Viewer描画用の基準。project座標から大座標による浮動小数点精度劣化を防ぐ。
- 大座標をそのままThree.jsへ投入しない（Local Originを引いて描画）。

--------------------------------------------------------------------------------
5. Unit
--------------------------------------------------------------------------------
- unit system: metric（m）
- 標高 / 座標 / 幅員 / 延長すべてメートル

--------------------------------------------------------------------------------
6. Road CIMとの整合
--------------------------------------------------------------------------------
- Road CIM（Phase 2）とTerrainは同一Project座標系（project coordinate）で重ねる。
- Road CIM geometry / Terrain geometryはどちらもProject Origin基準。
- ViewerはLocal Originを引いて描画（表示責任）。

--------------------------------------------------------------------------------
7. domain/render coordinate責任分離
--------------------------------------------------------------------------------
- domain coordinate = 正本（project.json・Terrain Module・Road Module）
- render coordinate = Viewer内でのみ有効（永続化しない）
- 変換は表示時に適用・正本を書き換えない

--------------------------------------------------------------------------------
8. Freeze対象
--------------------------------------------------------------------------------
- domain XYZ規約（X=軸方向/Y=横断/Z=標高）
- Three.js変換: x→x, y→z, z→-y
- Project Origin / Local Originの分離
- Viewer変換は表示責任
- metric unit
