================================================================================
統合設計 Phase 3-A  3-00 Terrain / Existing Conditions 責任分離Freeze
================================================================================
確定日: 2026-08-11

--------------------------------------------------------------------------------
1. Terrain Module
--------------------------------------------------------------------------------
Terrain Module = 地面・地表面の正本。

対象:
- terrain source
- terrain points
- elevation
- TIN
- terrain surface
- coordinate context
- terrain metadata
- validation

Phase 3-Aでは最小Contractのみ定義し、本体（Import/TIN/Surface）は3-02以降。

--------------------------------------------------------------------------------
2. Existing Conditions
--------------------------------------------------------------------------------
Existing Conditions = 地面以外の現況構造物。

対象候補（Phase 3-Aでは本体を作らない）:
- 現況道路
- 河川
- 鉄道
- 既設橋
- 建物
- 防潮堤
- 池
- 地下埋設物（洞道 / 水道管 / ガス管 / 電気通信管路）

--------------------------------------------------------------------------------
3. 分離原則
--------------------------------------------------------------------------------
- Existing Conditions を Terrain へ無理に押し込まない。
- Terrain Module は地表面の正本のみを所有する。
- Existing Conditions は別責任として後続Phaseで定義する。
- Road（Phase 2）・Terrain・Existing Conditions はすべて
  Project Data Core配下の独立Moduleとして共存する。

--------------------------------------------------------------------------------
4. 接続
--------------------------------------------------------------------------------
Terrain Module
  ↓
Terrain Adapter / Module Core
  ↓
Project Data Core
  ↓
Persistence / Auto Save
  ↓
.spacerproj

UI / Viewer から Project JSON を直接変更させない。

--------------------------------------------------------------------------------
5. Freeze対象
--------------------------------------------------------------------------------
- Terrain = 地面・地表面の正本
- Existing Conditions = 地面以外の現況構造物（別責任）
- Module Core Contractに従って接続
- direct Project JSON mutation禁止
================================================================================
