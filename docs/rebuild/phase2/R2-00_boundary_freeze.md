================================================================================
Phase 2-A  2-00  責任境界Freeze / Road正本確定
================================================================================
確定日: 2026-08-11

--------------------------------------------------------------------------------
1. 目的
--------------------------------------------------------------------------------
Phase 2-AのRoad Module接続における責任境界をFreezeする。
Road Module・Project Data Core・他Module間の所有権・接続経路を明確化する。

--------------------------------------------------------------------------------
2. Road正本
--------------------------------------------------------------------------------
- RoadDesignDocument を road領域の正本とする。
- RoadDesignDocumentはProject Data Core配下のroadモジュール領域に格納する。
- 形式: Phase 1 ModuleDataRecordの{ state, data, validation }構造で包んで格納。
  data内にRoadDesignDocument本体を保持。

--------------------------------------------------------------------------------
3. Project正本
--------------------------------------------------------------------------------
- Project Data Core はProject全体の唯一正本（R1-02 schema / runtime validation尊重）。
- すべてのModuleはProject Data Coreを唯一の書き込み対象とする。

--------------------------------------------------------------------------------
4. 接続
--------------------------------------------------------------------------------
Road Module
  ↓
Module Core / Adapter（frontend/src/next/modules/adapter.ts）
  ↓
Project Data Core（modules.road）
  ↓
Persistence / Auto Save（R1-04）
  ↓
.spacerproj Export / Import（R1-05）

--------------------------------------------------------------------------------
5. 禁止
--------------------------------------------------------------------------------
- Road UI / LINER / geometry core が Project JSON を直接変更しない。
- 旧/pro/liner を新統合システムの正規導線として復活させない。
- ModuleはManager.updateProjectModule経由でのみData Coreへ書き込む。

--------------------------------------------------------------------------------
6. Road Moduleが所有するもの
--------------------------------------------------------------------------------
- RoadDesignDocument
- 道路設計入力
- 道路設計由来の幾何（Phase 2-02以降に接続）
- Road validation
- Road module state/status

--------------------------------------------------------------------------------
7. Road Moduleが所有しないもの
--------------------------------------------------------------------------------
- FEM力学データ
- 上部工設計正本
- 下部工設計正本
- 統合3D Viewer state
- Phase 3以降のterrain
- Phase 4以降のBridge Layout正本
- 成果品

--------------------------------------------------------------------------------
8. Freeze対象の不変事項
--------------------------------------------------------------------------------
- Module Contract（moduleId/status/state/data/validation）はPhase 1でFreeze済み。
- Road ModuleはこのContractに適合して接続する。
- RoadDesignDocumentのschemaId / schemaVersionは既存契約を尊重する。

--------------------------------------------------------------------------------
9. 未決事項
--------------------------------------------------------------------------------
- なし（Phase 2-Aの接続範囲で重大な未決事項は発生しなかった）。
  幾何計算本体の正本化はPhase 2-02以降。
================================================================================
