【3. canonical architecture】
- PDC（Project Data Core）唯一正本・modules.{road,terrain,bridgeLayout,superstructure,substructure,analysis,cim,deliverables}
- 各module: canonical document + schema + validator + adapter（read/write fail-closed）
- derived: snapshot/handoff/analysis/scene はcanonicalから決定論的再生成
- checksum: contentChecksum/modelChecksum（sha256・canonical JSON）
- stale/invalid: fingerprint比較・3-gate・fail-closed

【4. module responsibilities】
| module | responsibility |
|---|---|
| road | 線形計算・canonical road data・CIM面・図面/報告はdeliverables連携 |
| terrain | 地形mesh・既設参照 |
| bridgeLayout | 橋梁区間・支間割・支持点・span/support handoff |
| superstructure | 主桁/断面/材料/支承/荷重・2D/DXF/Quantity/3D |
| substructure | 下部工形状・pile grid・座標/Quantity/2D/3D |
| analysis | FEM組立・IF3 authoritative・結果表示/export |

| deliverables | 図面/報告/export統合（Phase 11で新設） |
