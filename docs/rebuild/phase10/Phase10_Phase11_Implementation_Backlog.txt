P0-06 Bridge Layout span/support表出力（BL-02）
- goal: span table/support表を成果品としてCSV出力（形式・列・checksum格納をFreeze）
- source: bridgeLayoutSpans/bridgeLayoutPlacement
- target: deliverables内（canonical=bridgeLayoutDocument・builder=bridgeLayout module所有）
- policy: 軽量REWRITE小・canonicalから導出・manifest/download=deliverables・CSV schema Freeze:
  - 単一CSVファイル（span行/support行をtype列で区別）・1行=1エンティティ
  - 共通superset列（1本）: type,id,index,supportType,label,startSupportId,endSupportId,startStation,endStation,spanLength,startSkew,endSkew,station,skewRad,terrainElevation
  - 行種別別 required/optional（必須=入力・optional=空文字可）:
    - span行（type=span）: required=type,id,index,startSupportId,endSupportId,startStation,endStation,spanLength・
      optional=label,startSkew,endSkew・空文字=supportType,station,skewRad,terrainElevation
    - support行（type=support）: required=type,id,label,station・optional=skewRad,terrainElevation,supportType・
      空文字=index,startSupportId,endSupportId,startStation,endStation,spanLength,startSkew,endSkew
  - 単位（列単位）: station/length=m（精度3桁）・skew/角度=rad（精度6桁）・index=整数・label/type/id=文字列・
    terrainElevation=m（精度3桁・未設定=空文字）
  - ソート: station昇順（span行はstartStation昇順）
  - 文字コードUTF-8・改行LF・quoting規則のみRFC 4180（適用範囲を明記）
  - checksum: canonical contentChecksumをmanifestとpreamble行へ格納
  - preamble（1行目）文法（Freeze）: #spacer:type=bridge-layout;version=1.0;checksum=<hex>
    ・BL-02 parserは1行目を検証して読み飛ばす（必須）
    ・2行目=CSV header（superset列）・3行目以降=データ
    ・preamble/header存在・checksum一致をP0-08で検証
- module: bridgeLayout/deliverables
- tests: 表生成test・CSV byte/content検証（列/単位/null=空文字/ソート/checksum/quoting）

P0-07 Reference Mountain fixture import経路（Phase 12開始必須条件）
- goal: 「空Project＋明示的なReference Mountain fixture import」を受入セットアップとして確立。
  自動seedを暗黙利用しない。
- source: createReferenceMountain（terrain/referenceMountain.ts）・既存E2E（referenceMountainE2E/referenceRoadE2E）パターン
- target: 受入用fixture importer（deliverables module UI・一意）
- policy:
  - 正式import経路（一意・代替なし）: deliverables moduleの「fixture import」UIのみ
    route = /app/projects/{id}/modules/deliverables・import API = POST /api/rebuild/fixture/import（backend）
  - 所有: 全bundle要素のimport所有=deliverables module（一意）
  - fixture version: REF-MOUNTAIN-1・bundle要素（schema version固定）:
    | 要素 | schema version | 生成元 | 必須payload |
    |---|---|---|---|
    | road | CanonicalRoadData 0.3.0 | createReferenceMountain.roadHorizontal/Vertical/CrossSection | alignment/vertical/crossSections |
    | terrain | TerrainDocument 0.1.0 | createReferenceMountain.terrainGrid | grid/mesh |
    | existing | ExistingConditionsDocument 0.1.0 | createReferenceMountain.existing | entities[] |
    | bridgeLayout | BridgeLayoutDocument 0.1.0 | bridgeLayoutFromRange(100,450)+P1@300 | bridgeId/range/supports/spans |
    | superstructure | SuperstructureDocument 0.1.0 | generateSuperstructureFromLayout+declared section | girder/section/material/deck/bearing |
    | substructure | SubstructureDocument 0.1.0 | generateSubstructureFromLayout | supports/placement/pile |
    | analysisSettings | AnalysisSettings 1.0.0 | declared section/material | section/material/settings |
  - 適用順序: road→terrain→existing→bridgeLayout→superstructure→substructure→analysis（固定）
  - 原子性（Freeze）: 全bundle要素を先にschema/checksum検証→単一transactionで全module commit→provenance記録。
    途中失敗時はProjectを無変更（rollback）とする（部分適用禁止）
  - REF-MOUNTAIN-1は全要素必須: 6 moduleChecksumsとexistingChecksumは全て非null必須（欠落moduleはimport拒否）
  - checksum: module別contentChecksum集合（road/terrain/bridgeLayout/superstructure/substructure/analysis）をprovenanceに記録。
    existingはmetadata配下のためexistingChecksumとして別途記録（moduleChecksums対象外であることを明示）
  - provenance schema: {fixtureId, fixtureVersion, importedAt, moduleChecksums:{moduleId: hexDigest|null}, existingChecksum: hexDigest|null, operator}
    ※ fixtureVersion（oracle/report chain と同一field名に統一）
  - moduleChecksums固定キー: road, terrain, bridgeLayout, superstructure, substructure, analysis（analysisSettings→analysisに正規化）
  - digest形式: sha256 hex・null条件: module未設定時
  - analysisSettingsは分析設定としてanalysis moduleChecksumの生成元（analysisSettings→analysis対応を確定）
  - checksum比較: REF-MOUNTAIN-1は全module非null必須（nullはimport拒否）・将来のoptional moduleのみnull許容（現時点は非null一択）
- module: 全module横断・import所有=deliverables module一意（代替なし）
- tests: fixture import round-trip test・checksum一致test
- E2E: 空Project→fixture import→解析→成果品（Phase 12シナリオの前段）・P0-07 PASS必須
- acceptance: 投入地点・操作・provenance（fixtureId/version/moduleChecksums）記録
- risk: 中
