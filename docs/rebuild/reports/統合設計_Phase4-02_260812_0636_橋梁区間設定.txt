3. Bridge Range仕様
--------------------------------------------------------------------------------
- 格納: bridgeRange.startStation / endStation（BridgeLayoutDocument唯一正本）
- 橋長: bridgeLength = endStation - startStation（原則・自動算出）
  ※Road Moduleのstation体系に別の正式定義は存在しないため、
    physical distance [m]（origin 0・equation なし）を正式定義として採用
- 必須validation:
  - finite number（NaN / Infinity reject）
  - startStation < endStation（== も reject）
  - start/end が Road Alignment 範囲内（0 ≤ station ≤ totalLength）
  - roadReference 有効（moduleId: road）
  - alignmentReference 有効（未保存段階でも現在のRoad Alignmentへ解決可能なら有効）
  - bridgeLength 存在時は end - start と一致（不一致 reject）

--------------------------------------------------------------------------------
4. Road reference（Step A）
--------------------------------------------------------------------------------
- BridgeLayoutDocument.roadReference.alignmentId から Road Module 正本を参照
  （正本複製なし・ID/reference接続）
- readRoadAlignmentContext: Road Module の horizontal / vertical / crossSections を
  buildRoadIntermediate で評価し、alignmentId / totalLength / coordinatePolicyId を解決
- Road 存在しない / alignment 存在しない / 要素なし → fail-closed（ok=false + issues）
- Bridge Layout UI から Road JSON は変更しない（RoadModuleShellPage のみが Road を保存）

--------------------------------------------------------------------------------
5. start / end station
--------------------------------------------------------------------------------
- startStation → A1 / endStation → A2（station を正式保存）
- ユーザーが測点を変更すると橋長・A1/A2候補・Terrain/Existing参照が再計算
  （applyBridgeRangeToDocument / assembleBridgeLayoutView）

--------------------------------------------------------------------------------
6. bridgeLength
--------------------------------------------------------------------------------
- bridgeLength = endStation - startStation（自動算出）
- BridgeRange.bridgeLength は算出スナップショットとして保存（正式値は常に再算出）

--------------------------------------------------------------------------------
7. A1/A2生成仕様（Step B）
--------------------------------------------------------------------------------
- A1/A2 は「橋梁端部の配置点 / 配置線 / downstream handoff用の最小配置情報」
  （橋台躯体・パラペット・翼壁・基礎・杭・詳細CIM・構造照査は対象外）
- computeAbutmentPlacementCandidate: Road Module 正式API（buildRoadIntermediate.sample）で
  各測点の以下を取得
  - station / domain X / domain Y / elevation / tangent（azimuth）/ grade / display
- AbutmentPlacement.placement スナップショット:
  domainX / domainY / elevation / tangentAzimuthRad / terrainElevation /
  roadReferenceId / coordinateContextId / capturedAt

--------------------------------------------------------------------------------
8. XYZ / elevation / tangent
--------------------------------------------------------------------------------
- domain XYZ: X=道路軸方向 / Y=横断方向 / Z=標高（metric）
- 変換は Road Module（liner core pointAtStation/evaluateRoadCenterline3D）へ委譲し再実装しない
- elevation: 縦断（vertical）評価値（z）
- tangent: azimuth [rad]

--------------------------------------------------------------------------------
9. skew
--------------------------------------------------------------------------------
- 新正本規約: 反時計回り正（counterclockwise-positive）
- 旧資産の別符号規約は混入させない
- Phase 4-02 では A1/A2 の skewAngleRad は null のまま（配置線の向きは未設定）
  ※変換が必要な場合は Adapter 境界で明示する方針は維持

--------------------------------------------------------------------------------
10. Terrain reference（Step B・D）
--------------------------------------------------------------------------------
- lookupTerrainElevation: getGridElevation 相当（bilinear補間）
  - gridなし / 点がTIN外 → null（明確な参照不能）
- assembleBridgeLayoutView で A1/A2 直下の地盤標高と差を参照
  - A1 terrain elevation / A2 terrain elevation
  - A1 road elevation - terrain elevation の差（diffA1 / diffA2）
- getProjectTerrainGrid: Project地形サーフェス（Phase 4-02 では
  terrain surfaceReference 解決時に Reference Mountain の地形サーフェスを
  Project地形として使用。Terrain Module の grid は Project JSON に非保持のため）
- Terrain がない場合でも橋梁区間データは破壊しない（available=false の warning）
- 地形から橋梁区間を自動決定しない

--------------------------------------------------------------------------------
11. Existing reference（Step B）
--------------------------------------------------------------------------------
- 橋梁区間 bbox（Road中心線サンプル + margin）と Existing entity geometry の
  線分-bbox交差判定（isExistingNearRange / collectExistingNearRange）
- 本格的な自動干渉判定エンジンは作らない（最小参照のみ）
- bridge range 周辺の entity を参照・表示可能 / reference切れ検出
- 自動的に橋梁区間を変更しない
