2. Target Architecture
====================================================================

```
旧LINER実務Editor UI（KEEP/RESTORE/ADAPT）
  ↓ 編集
Canonical Road Input（Single Source of Truth・modules.road.data.roadData）
  ↓ 導出（deterministic）
RoadDesignDocument（entity-registry契約・handoff/interchange）
  ↓ Project Data Core
Road Calculation / Intermediate Result（LINER kernel・現road wrapper）
  ↓ 2D Preview（MERGE）・3D Road/Road CIM・Terrain/Existing・Bridge Layout・
    Superstructure/Substructure・Analysis・Integrated 3D
```

- 旧LINERと新Roadを2つの別システムとして残さない。
- 新統合システムRoad Moduleを正規入口とし、旧LINER実務入力能力を救出・適合。

====================================================================
3. Single Source of Truth
====================================================================

- **Canonical Road Input = 旧LINER `LinerDomainDraftVNext` スキーマ**（frontend/src/liner/schema/types.ts:287）を `modules.road.data.roadData` へ保存。
- roadInput（緩い型）: 廃止/移行・read-only保全。
- project.liner: legacy read-only保全・migration source・`_meta.legacyId`保持。
- RoadDesignDocument: derived（正本から決定論再生成）・handoff/interchange。
- derived（intermediate/mesh/CIM）: 永続しない（再生成）。
- version migration registry・atomic migration protocol・conflict comparator・
  dependency-scoped fingerprint・runtime rollback互換・所有境界（Road/BridgeLayout/RoadDesignDocument/Analysis）をFreeze。

====================================================================
4. Canonical Road Data
====================================================================

- schema: LinerDomainDraftVNext準拠（alignments・measuredGrid・drawingSettings・ldist/haunch/hoso・generationSettings・sampling）+ `_meta`（source/migratedAt/roadLabel）。
- version: draft schema 0.3.0継承・supported 0.1.0-0.3.0。
- checksum: canonical JSON sha256（sort_keys・決定論）。
- validation: `schema/validateProjectLinerExtension.ts` ADAPT。
