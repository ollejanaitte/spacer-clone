2. Integrated 3D Scene Contract（FROZEN）
====================================================================

```ts
// src/next/modules/cim/integrated3dScene.ts
export type CimLayerId =
  | "terrain" | "existing" | "roadPavement" | "bridgeLayout"
  | "superstructure" | "substructure" | "foundation" | "bearing"
  | "femNodes" | "femMembers" | "supports" | "springs"
  | "loads" | "deformed" | "reaction" | "result"
  | "labels" | "reference";

export interface CimEntityMetadata {
  readonly sourceModule: CimLayerId;
  readonly sourceEntityId: string;   // 正本側ID（例: supportId/spanId/partId/entityId/roadElementId/fem nodeId）
  readonly stableId: string;         // シーン内一意ID（例: sub:{supportId}-{PART}-NN）
  readonly coordinateContext: string;// 例: "world/road:{alignmentId}" / "world"
  readonly label?: string;
  readonly meta?: Record<string, unknown>;
}

export interface Integrated3DScene {
  readonly ok: boolean;
  readonly issues: readonly { path: string; message: string }[];
  readonly layers: { [K in CimLayerId]: THREE.Object3D | null };
  readonly metadata: Map<string, CimEntityMetadata>;  // stableId -> metadata
  readonly bounds: THREE.Box3;
  readonly regeneratedFrom: { module: string; checksum?: string }[]; // 追跡
}
```

- 生成関数 `buildIntegrated3DScene(manager, projectId)` は各正本を read して
  レイヤーを組み立てる。タイムスタンプ・乱数・非決定的入力は geometry に
  含めない（roadCimGeometry.generatedAt 等は metadata 側へ分離）。
- すべての Object3D は `userData.cimMetadata: CimEntityMetadata` を保持する。

3. Coordinate / ID 統合（FROZEN）
====================================================================

## 3-1. World Coordinate
- Domain座標（x=easting, y=northing, z=elevation, 単位m）を正本座標とする。
- Three表示変換は `frontend/src/next/modules/renderCoordinate.ts` のみ:
  `three = (x, z, -y)`, `domainVerticesToThree`, `threeToDomain`。
- localOrigin は既定 (0,0,0)。Terrain local origin（Origin3）があれば適用。
- 全レイヤーは同一 world 空間へ配置。別の表示変換の導入・二重適用を禁止。

## 3-2. 表示変換の単一化（MERGE）
- viewer.tsx 内インライン `[p.x,p.z,-p.y]` → `domainToThree` 委譲
- threeFactory.swapToYUp（下部工Z-up）→ renderCoordinate 委譲（方向一致確認済み）
- viewer/coordinateTransform.applyViewerDisplayTransform → renderCoordinate 委譲
- これらは ADAPT として Phase 8-02 で統一する。

5. Road CIM Surface（FROZEN）
====================================================================

- canonical roadData → loadRoadEditorDraft → buildRoadIntermediate
  （sampleInterval 5m既定・延長/測点/azimuth/grade/leftRightWidth/leftRightSlope）
- 各sampleで中心点 + 左端/右端（evaluateRoadWidth: widthChangePoints拡幅反映、
  evaluateRoadCrossfall: 左右横断勾配反映）を計算し、triangle strip で面を張る。
- roadMesh ADAPT: widthChangePoints（拡幅）反映・leftSlopePercent 反映。
- metadata: road-surface:{alignmentId}・alignmentId・チェックサム。

8. Persistence / STALE（FROZEN）
====================================================================

- 統合3D自体を永続化しない（毎render正本から再生成）。
- layer可視状態などのUI状態は localStorage（per-project key）で復元（任意・WP-J）。
- Save → 完全終了 → restart → reopen → Integrated 3D再生成 → 整合確認。
- .spacerproj export → import → Project復元 → Integrated 3D再生成 → 整合確認。
- 上流変更時: Road変更→Road CIM→Bridge影響→Super/Sub→Analysis stale。
  line/support削除でsource消失時は INVALID / fail-closed。
