  surfaceReference / assetReferences / validation

--------------------------------------------------------------------------------
7. Coordinate system / Unit / Project Origin / Local Origin
--------------------------------------------------------------------------------
- domain XYZ規約: X=道路軸方向 / Y=横断方向 / Z=標高（Phase 2 Road CIMと同一）
- Three.js変換（表示責任）: x→x, y→z, z→-y（threeCoords踏襲）
- Project Origin: Project Data Core内の正本座標基準（global→project変換の起点）
- Local Origin: Viewer描画用の基準（大座標による浮動小数点精度劣化を防ぐ）
- unit: metric（m）
- domain/render coordinate責任分離（Viewer変換は表示責任・正本を書き換えない）

詳細: docs/rebuild/phase3/R3-00_coordinate_origin_freeze.md
