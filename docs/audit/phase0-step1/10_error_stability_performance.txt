1. 起動時エラー
--------------------------------------------------------------------------------
- Electron: Gtk-Message "Failed to load module xapp-gtk3-module"（無害）
- Electron: VAAPI version too old (1.14 < 1.17)（media/gpu、無害）
- backend-start.err.log: エラーなし（起動情報のみ）
- vite: 正常（199ms ready）
判定: 起動は安定。

--------------------------------------------------------------------------------
2. 通常操作中の console / renderer エラー
--------------------------------------------------------------------------------
a) 【重大】移動荷重解析 → UI クラッシュ（S2）
   - 再現: 任意モデル読込 → 入力チェック → 移動荷重
   - エラー: TypeError: Cannot read properties of undefined (reading 'filter')
     at buildResultViewModel (resultViewModel.ts:183)
     at ResultTablesContent (ResultsPanel.tsx)
   - 結果: 「予期しないエラーが発生しました。再読み込み」(ErrorBoundary)
   - 原因: 移動荷重 API result に displacements が無いのに
     result.displacements.filter() を実行。
   - 発生頻度: 100%（毎回再現）

b) WebGL GPU stall 警告（headless Chromium でのみ）
   - "[.WebGL-*]GL Driver Message (OpenGL, Performance, GL_CLOSE_PATH_NV, High):
     GPU stall due to ReadPixels"
   - 実機 Electron（compat-gpu-blocklist）ではスプラッシュ〜表示まで問題なし。
   - 本質的にはスイフトシェーダ等での性能警告。実ユーザー環境では要注意。

c) THREE.Clock deprecated warning（下部工画面）
   - "THREE.Clock: This module has been deprecated. Please use THREE.Timer instead."
   - 無害だがライブラリ更新の際に対応必要。

d) React DevTools 案内（開発用、無害）

--------------------------------------------------------------------------------
3. API エラー
--------------------------------------------------------------------------------
- /api/projects/validate, /api/analysis/* は正常応答。
- 固有値/応答スペクトル: 質量ケース・スペクトル設定が無いモデルでは
  バックエンドが "failed" 結果を返す（入力不足に対する適切な失敗、想定内）。
- 404/422/500: 通常操作では未発生。

--------------------------------------------------------------------------------
4. 安定性・性能
--------------------------------------------------------------------------------
- 起動時間: Electron フル起動 約10〜20秒（backend+compile+electron）。
  ブラウザレンダラロード: 約3.7秒（vite キャッシュ無し）。
- 静的解析: 数 ms 級（小規模モデル）。
- 固有値: 3ms（2節点1部材）。
- 大規模モデル性能: アニメーション時に rAF 毎にシーン全体再構築（ThreeViewport.tsx:264）。
  数千節点+ソリッドでは負荷懸念（推測、未計測）。
- メモリ: 通常操作で異常なし（実測なし）。

  ポート 5211-5225 帯で稼働中。正規ポートには影響なし。
  クリーンアップ候補（監査対象外）。
