6. 正規起動方法（一意確定）
--------------------------------------------------------------------------------
Ubuntu/WSL の正規起動:
    ./start-ubuntu.sh                # 既定: Apollo Phase1-NN + Electron + compat-gpu-blocklist
    ./start                          # Linux では start-ubuntu.sh を exec する wrapper
    ./start-ubuntu.sh --web          # Electron を使わず Vite のみ (http://127.0.0.1:5173)
    ./start-ubuntu.sh --backend-only # FastAPI のみ (http://127.0.0.1:8000)

README / docs/development/runtime-ubuntu.md と start-ubuntu.sh の実装が一致する。
既定モードは APOLLO_MODE=1 + GPU_MODE=compat-gpu-blocklist で
「npm run electron:dev:apollo」を実行し、vite(apollo mode) + electron が起動する。

ポート:
- backend : 127.0.0.1:8000 (FastAPI, title="spacer-clone MVP API", version=0.3.0-preview)
- vite    : 127.0.0.1:5173 (strictPort, apollo mode)
- Electron main window: 1280x820 (loads http://127.0.0.1:5173)

環境変数:
- HOST (default 127.0.0.1), PORT (default 8000), GPU_MODE, PYTHON_BIN
- VITE_APOLLO_PHASE1_ENABLED=true 等は frontend/.env.apollo に定義 (Apollo phase1 feature flags)
- SPACER_AUTOMATION=1 で Electron のスプラッシュをスキップ (テスト用)

実測:
- ./start-ubuntu.sh を起動し、backend OK -> vite ready (199ms) -> Electron 起動を確認。
- Electron ウィンドウ "SPACER Clone MVP" (1280x820) が表示された。
- 起動直後の画面は日本語ランディング「簡易構造計算ソフト」
  (学習編 / 入門編 / 実務編)。
