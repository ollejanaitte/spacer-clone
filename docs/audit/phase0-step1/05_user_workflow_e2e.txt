A. 新規業務フロー（実務編 → BusinessProject → ツール起動）
--------------------------------------------------------------------------------
手順:
1. Electron 起動 → ランディング（簡易構造計算ソフト）
2. 実務編 → 業務から設計 → 業務一覧を開く
3. 新規業務 → 業務件番/業務名/設計段階 入力 → 作成
4. BusinessWorkspace 表示（概要タブ）
5. 道路線形タブ →「LINER を開く」→ /pro/linear-coordinate
6. GUI で線形入力（または山岳サンプル）→ LINER 編集
7. 各セクションで設計作業
8. 保存 → 終了

実測結果:
- 手順1〜5: PASS（新規業務作成 → BusinessWorkspace → LINER 起動まで到達）
- 手順6: LINER 編集（GUI/サンプル）は動作する。ただし「実入力→設計完了」まで
  完走させるには多くの作業が必要で、この監査ではサンプル読込+一部編集まで実施。
- 手順7: 上部工(Apollo)=モデル入力のみ・解析不可。下部工=15チェック未実装。
  解析(FEM)=実解析可。統合3D=サンプル専用。成果物/データ=未実装。
- 手順8: 保存は BusinessWorkspace の「保存」（localStorage マニフェスト）のみ。
  各ツールの作業データは project.json に統合保存されない。

FIRST BREAKPOINT (新規業務):
- 最初の停止点: 下部工「設計計算」（15チェック hold_not_available）または
  Apollo「構造解析・結果表示 未実装」。
- つまり「道路線形を入力 → 上部工 → 下部工 → 解析 → 成果物」の設計チェーンを
  完結することができない。途中のツールは動くが、最後の設計・成果物が出せない。

--------------------------------------------------------------------------------
B. 継続業務フロー（既存業務を開く → 編集 → 再計算 → 保存）
--------------------------------------------------------------------------------
手順:
1. Electron 起動 → 実務編 → 業務一覧
2. 既存業務を開く
3. 既存値確認 → 編集
4. 再計算
5. 3D 確認
6. 保存 → 終了

実測結果:
- 手順1〜2: PASS（同一ブラウザプロファイルなら localStorage から業務が復元される）
- 手順3: 業務ワークスペースに「編集できる値」がほぼ無い（メタデータのみ）。
  実際の設計値は各ツール側。
- 手順4: 解析は /pro（クイック解析）で実行可。
- 手順5: 3D は /pro Viewer3D（FEM 骨組み）か LINER Main3D（サンプル）。
- 手順6: 保存はツールごとに分離。業務ワークスペースの保存では設計値は保存されない。

FIRST BREAKPOINT (継続業務):
- 「業務を開き直して作業を再開する」ことはできる（localStorage）が、
  「業務の設計データ」が業務に紐付いて保存されないため、実際の継続業務は
  各ツールのファイル保存に依存する。
- メイン FEM モデルは再起動時に自動復元されない（STEP 1-06 参照）ため、
  クイック解析で作ったモデルは手動 Open が必須。

C-4. 入門編サンプル（教育）:

FIRST BREAKPOINT (Sample系):
- 共通して「計算・設計・成果物」段階で停止。
  - Apollo: 構造解析未実装

  - 入門編: 実解析なし
