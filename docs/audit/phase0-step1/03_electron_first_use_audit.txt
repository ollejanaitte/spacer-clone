1. Electron 起動確認
--------------------------------------------------------------------------------
- 起動方法: ./start-ubuntu.sh（Apollo Phase1-NN + Electron + compat-gpu-blocklist）
- 結果: 正常起動。ウィンドウ "SPACER Clone MVP"（1280x820）が表示された。
- 起動時間: 依存確認〜backend OK〜vite ready(199ms)〜Electron ウィンドウ表示まで
  おおよそ 10〜20 秒（初回は npm/compile 次第でより長い）。ブラウザ側のレンダラ
  ページロードは約 3.7 秒（Playwright 実測、vite キャッシュ無し時）。
- 起動時エラー: バックエンドログにエラーなし。
  - Gtk-Message: Failed to load module "xapp-gtk3-module"（無害）
  - VAAPI version too old（media/gpu、無害）
- Electron スプラッシュ: 「Spacer Clone を起動しています」→「バックエンド」→「UI」の
  進捗スプラッシュが実装されている（SPACER_AUTOMATION=1 でスキップ可）。

2. 最初に表示されるもの
--------------------------------------------------------------------------------
「簡易構造計算ソフト」の日本語ランディングページ。
- 📚 学習編「橋ってなんだろう」（動画や記事で学べる。対象: はじめての方〜発注者）
- 🌉 入門編「サンプルで簡易計算」（用意された橋を地震でゆらしてみよう。教育用途）
- 🏗 実務編「実荷重で本格検討」（実際の荷重・条件で設計検討。対象: 設計実務者）
- 「このアプリについて」
- 注記: 「※ いつでも他の編に切り替えできます」

ユーザー目線の評価: 初見でも「自分に合う入口」を選べる親切な構成。
ただし「簡単な構造計算ソフト」という文言が、実際の機能範囲（設計実務未認可、
Apollo解析未実装等）と釣り合わない可能性はある。

--------------------------------------------------------------------------------
3. 新しい業務を始める方法（実務編）
--------------------------------------------------------------------------------
実務編 →「業務から設計」(Business Project) →「業務一覧を開く」
→「新規業務」→ 業務件番 / 業務名 / 設計段階 を入力 → 作成
→ BusinessWorkspace（8タブ）表示。
判定: 概ね明確。ただし「実務編」の入口が「実荷重で本格検討」を謳う一方で、
実際の業務ワークスペースには「実設計データ」が存在しない（メタデータのみ）。

--------------------------------------------------------------------------------
4. 既存業務を開く方法
--------------------------------------------------------------------------------
実務編 →「業務から設計」→「業務一覧を開く」→ 一覧から業務を開く。
判定: 明確。ただし業務一覧は localStorage に依存し、Electron のプロファイルが
変わると業務が消える（STEP 1-06 で詳述）。

--------------------------------------------------------------------------------
14. まとめ（初見ユーザー視点）
--------------------------------------------------------------------------------
- 良い点: 日本語UI、役割別入口（学習/入門/実務）、戻る手段、保存フィードバック、
  WebGL フォールバック等、初見配慮が多数ある。
- 問題点:
  1) 実務編を選んでも「実際の設計作業」へ到達できる道具（実設計データ、Apollo解析、
     下部工設計、成果物）が未実装・プレースホルダ。画面はあるが業務が進まない。
  2) 開発者向けボタン・用語（TEST/不可シミュレート/FATAL/Apollo shell 等）が露出。
  3) 学習編・入門編はリンク/文言のみで、学習コンテンツ・実解析がない。
  4) 起動ツールから業務ワークスペースへの直接戻りが無い。
- FIRST BREAKPOINT（初見）: 実務編で「新規業務を作成」はできるが、その業務で
  設計作業（道路線形の実入力→上部工→下部工→解析→成果物）を完結できない。
  最初に業務が止まるのは「成果物」「データ」タブ（未実装）または各ツールの
  解析・設計段階。
