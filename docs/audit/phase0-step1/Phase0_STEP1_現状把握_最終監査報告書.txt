1. Executive Summary
--------------------------------------------------------------------------------
spacer-clone は「FEM 解析エンジン（本物の数値計算）」「LINER 道路線形（本格実装）」
「IF3 正規化・永続化」「原子 JSON 保存」を中核資産として持つ、開発中の橋梁設計
プラットフォームである。Electron は正常起動し、日本語の役割別入口
（学習編/入門編/実務編）を持つ。

しかし実務ソフトとして見た場合、以下の重大な制約がある:
- 設計業務チェーン（道路線形→上部工→下部工→解析→成果物）を完結できない。
  Apollo の構造解析・結果表示は未実装、下部工の設計計算は MOCK、成果物は未実装。
- 保存はメイン FEM がファイルダウンロードのみで、再起動時に自動復元されない
  （autosave 凍結）。backend 保存 API は UI 未使用。→ 高データ損失リスク。
- 移動荷重解析で UI がクラッシュする（S2、100%再現）。
- Source of Truth が分散・多重管理（座標系5箇所、解析結果4重、LINER↔FEM非同期）。
- 3D は「FEM骨組み（実データ）/既定断面の仮形状/サンプル専用」の3系統。CIM 未実装。
- 教育フロー（学習編/入門編）はプレースホルダ。
