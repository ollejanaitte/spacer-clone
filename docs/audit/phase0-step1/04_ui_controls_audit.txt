  節点/部材数が反映される。例: Cantilever Tip Load, 節点2/部材1/材料1/断面1/支点1/荷重1。

  タイムアウトした。Electron ではネイティブ保存ダイアログを使用する実装
  (desktop/projectFileDialog)。STEP 1-06 で Save→Restart→Load を通しで検証する。

[入力チェック (Validate)] 判定: PASS
- 有効モデルで「OK」表示。Toolbar ステータス「OK」。

[静的解析] 判定: PASS
- 結果ステータス「Success」。結果テーブル表示（変位/反力/部材力）。
- 実データ: ソルバ scipy_sparse。

[固有値] 判定: PASS（質量ケース付きモデルのみ）
- cantilever-eigen で「Success」。Mode 表示、ソルバ scipy_eigh、計算時間 3ms。
- cantilever_tip_load（質量ケース無し）では「Failed」（入力不足は想定内）。

[応答スペクトル] 判定: PARTIAL
- 質量+スペクトル設定済みモデルでのみ動作。tip_load では Failed（想定内）。

[影響線] 判定: PASS
- simple_beam_center_load で「Success」。影響線グラフ表示。

[移動荷重] 判定: FAIL（S2 クラッシュ）※重大
- 再現手順: 任意モデル読み込み → 入力チェック → 移動荷重 → 即クラッシュ
- 結果: 「予期しないエラーが発生しました。再読み込み」(ErrorBoundary)
- 原因: 移動荷重 API の result に displacements が無いのに
        buildResultViewModel (resultViewModel.ts:183) が result.displacements.filter() を
        実行し TypeError → React レンダリングクラッシュ。
- 証拠: TypeError: Cannot read properties of undefined (reading 'filter')
        at buildResultViewModel (resultViewModel.ts:13→実際は183)
- 影響: 移動荷重解析を使うとアプリ全体が白画面相当のエラーバウンダリになる。
- 判定: S2 主要機能故障。回避策なし（使用不能）。

[出力 JSON] 判定: PASS
- result.json がダウンロードされる。

[出力 CSV] 判定: PASS（IF3 権威ゲート通過時）
- displacements.csv 等がダウンロードされる。ゲート未通過時はブロック表示。

[出力 PDF] 判定: PARTIAL
- 新しいウィンドウで HTML レポートを開きブラウザ印刷で PDF 化（真の PDF 生成ではない）。

[橋梁モデル作成 (BridgeWizard)] 判定: PARTIAL
- モーダルが開く。Step 1/6 道路条件（車線数/車線幅/中央分離帯幅/歩道幅/高欄幅 + 横断
  プレビュー y 座標自動計算）。6ステップのウィザード。バックエンド API 依存。
- 全ステップ完走・FEM 反映まで本監査では未検証（STEP 1-08 で評価）。

[時刻歴応答解析を開く] 判定: PASS
- モーダルが開く。地震波読込→入力確認→解析実行→結果確認のウィザード。
- 「未設定」状態から「入力チェックへ」「解析実行へ」ボタンあり。

[A/B 比較] 判定: PASS
- /pro/compare へ遷移。A 読取専用/B 編集、解析、3D 比較、モード選択等。

[サンプルを読み込む（空モデル時）] 判定: FAIL（UX 不一致）
- FEM ワークスペースの空状態で押すと、FEM サンプルではなく LINER 山岳サンプル
  (mountain-viaduct-500) が読み込まれ LINER 編集画面へ遷移する。
- ユーザー期待（FEM サンプル）と実挙動（LINER サンプル）が不一致。
- さらに backend /api/examples の FEM サンプル (cantilever 等) は UI から読み込む
  手段が無い（frontend loadExamples は UI 未配線）。

[LINER 起動ランチャ (/pro/linear-coordinate)] 判定: PASS
- GUI入力 / JIP-LINER PDF写経 / 山岳サンプル の3択。

[Apollo (/pro/apollo)] 判定: PARTIAL
- モデル入力・undo/redo・dirty guard は動作。サンプル橋梁(200m級5径間)読込可。
- 構造解析・結果表示は未実装（画面に明示）。
