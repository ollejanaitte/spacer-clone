1. システム全体構成（実測）
--------------------------------------------------------------------------------
Lobby(/) → 学習編(/learn) / 入門編(/level0) / 実務編(/pro/platform)
実務編 → DesignPlatformHome(/pro/platform) → BusinessList(/pro/platform/businesses)
       → BusinessWorkspace(/pro/platform/businesses/:id)
       → クイック解析(/pro)
クイック解析(/pro) = FEM ワークスペース（節点/部材/支点/荷重入力 + 解析 + 3D + 出力）
LINER(/pro/linear-coordinate, /pro/liner/*)
Apollo(/pro/apollo)
Substructure(/pro/liner/substructure)
Main3D(/pro/liner/main3d)
Importer(/pro/importer/*)
Compare(/pro/compare)

Frontend: React19 + Vite7 + Three.js/ReactThreeFiber + Recharts + MakerJS/JSCAD
Backend : FastAPI (port 8000) + Python solver (scipy/numpy)
Desktop : Electron (main/preload, 1280x820)

5. 特に重要な発見（実機操作で確認したユーザー視点の問題）
--------------------------------------------------------------------------------
1) /pro の空モデル状態で「サンプルを読み込む」を押すと、FEMサンプルではなく
   LINER 山岳サンプルが読み込まれ、LINER 編集画面へ遷移する（App.tsx empty-model-state）。
   → ユーザーが「FEMサンプル」を期待する箇所で「LINERサンプル」になる UX 不一致。
2) 入門編「結果を計算」の結果は「短い橋の橋です。」等の文言のみ。実解析なし。
3) 実務編 BusinessWorkspace の全セクション進捗は「未定義」固定。業務実体なし。
4) 成果物/データ タブには起動ボタンが無く、案内文のみ（プレースホルダ）。
5) 下部工計画画面に「FATAL 1」表示が確認された（詳細は STEP 1-10 で調査）。
6) 学習編の動画・記事リンクは全てダミーURL。
