# 13 — Lateral Bracing L-Angle Section Spec

## Scope
Upper/lower `LateralBracing` BraceMembers (and optionally sway diagonals) use L-angle solid instead of Ø0.08 cylinder.

## DEC-S5-0007 (DECIDED_DRAFT + PENDING_ER dims)
Parameters: `legA_m`, `legB_m`, `thickness_m`, `orientation` (which legs face girder/web).

## DEC-S5-0008 (DECIDED_DRAFT)
Sample catalog CAT-S5-LAT-* are UNVERIFIED_DEVELOPMENT placeholders pending ER-002. Must display provenance in UI.

## Placement
Reuse existing flange connection Z / bay diagonals; only section representation changes in P5.
