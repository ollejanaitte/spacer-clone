# 19 — STL and Visualization Policy

| Kind | Viewer | STL default |
|------|--------|-------------|
| Structural (girder, XB, bracing, deck, haunch, app, bearing) | yes | yes |
| Pavement | yes | yes (deck surface) |
| Road markings | yes | **no** (DEC-S5-0004) |
| Markers | optional | opt-in |

Export metadata must list excluded viz-only kinds.
