## WorkflowStateModel

- **Generated by:** `buildWorkflowStateModel(project)` in `frontend/src/apollo/workflow/index.ts`
- **Uses:** `registry.ts` (WF-01..15), `evaluators.ts`, `selectors.ts`, `dependencies.ts`, `capabilityRegistry.ts`, `diagnostics.ts`, `recommendedAction.ts`
- **UI consumers:**
  - `WorkflowControlScreen` → progress + 15 cards
  - `GuidedModeShell` diagnostics aside (recommended step + first 12 diagnostics)
- **Must not change for UI redesign:** evaluators, selectors, dependencies, capability registry, WF IDs/meanings, status derivation

|---------|----------|
