# Calculation Structure and Page Numbering Catalog

## 1. Purpose

Catalog the chapter/section structure, page numbering model, and PDF-to-printed
page mapping for the Reference Bridge 001 calculation book.

## 2. Page numbering model

| Item | Value |
|------|-------|
| PDF pages | 2226 |
| Printed pages | 1–2221 |
| Front matter | PDF 1–5 (cover, title, 3-page TOC) — no printed numbers |
| Content | PDF 6–2226 = printed pages 1–2221 |
| Offset | `printed_page = pdf_page - 5` (constant, verified at 10 points) |
| END marker | Printed page 2221 (PDF 2226) |
| Last content | Printed page 2216 (PDF 2221, 5.4.2 AR2 design) |

Offset verified at:
- PDF 6 → printed 1 (第1章 設計条件)
- PDF 10 → printed 5 (1.3 基本寸法一覧)
- PDF 110 → printed 105 (3.1 主構断面力の計算)
- PDF 286 → printed 281 (3.2 主桁の設計)
- PDF 670 → printed 665 (3.3 横桁の設計)
- PDF 866 → printed 861 (4.1 主構断面力の計算)
- PDF 2021 → printed 2016 (5.1 支承の設計)
- PDF 2221 → printed 2216 (5.4.2 AR2)

No gaps, skips, or unnumbered content pages found.
