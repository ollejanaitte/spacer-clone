# Excluded Formal Checks

The following remain **OUT OF SCOPE** for Step 5 and must not be implied by sample/Guided/3D work:

- Formal member OK/NG against adopted design codes
- Formal transverse load distribution certification
- Fabrication / connection / fatigue / weld / bolt design
- Claiming sample dimensions as national or project standards
- Claiming GUI appearance = engineering correctness
- NUMERIC_DESIGN_AUTHORIZATION grant
- DESIGN_OR_CONSTRUCTION_USE permission
