# 09 — Complete Sample Target

Target states after sample select + agreed apply transaction (values themselves undecided in Step 5-1):

| Gate | Meaning |
|------|---------|
| PRESET_SELECTED | Sample ID applied with disclaimer |
| INPUT_VALID | Required fields present for generation |
| GEOMETRY_READY | BSDD/solids current |
| QUANTITY_READY | Quantity model current (dev) |
| LOAD_READY | Load model current (dev) |
| ANALYSIS_READY | Analysis hookup runnable or explicit NOT_AVAILABLE |
| THREED_READY | Viewer shows expected visibility groups |
| EDITABLE | Guided + detail can edit same draft |
| DEVELOPMENT_ONLY | Safety labels intact |

See `complete_sample_target_matrix.csv` and `preset_editability_matrix.csv`.  
**Step 5-1 does not invent preset numeric standards.**
