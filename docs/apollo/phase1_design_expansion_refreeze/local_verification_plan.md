**Status:** REQUIRED BEFORE MERGE  
**Target branch:** `docs/apollo-phase1-design-expansion-refreeze`  
**Baseline:** `1fbcb3ea804f965b8f262284573f4f4d42dc2411`

## 目的

GitHub上で作成した再凍結文書が、ローカルの正本リポジトリ、既存Apollo実装、3D表示、テスト構成、ドキュメント構成と矛盾しないことを確認する。

この文書は、ユーザーまたはローカル作業担当者が実施する検証内容の保存先とする。検証結果は本ファイル末尾の「実施結果」へ追記するか、同ディレクトリに `local_verification_report.md` を新規作成して保存する。

## 必須検証

### LV-01 Git同期・作業ツリー確認

確認事項:

- ローカル `main` と `origin/main` のSHAが一致すること
- `origin/main` が少なくとも `1fbcb3ea804f965b8f262284573f4f4d42dc2411` を含むこと
- 未コミット変更、未追跡ファイルがないこと
- 再凍結ブランチを安全に取得できること

推奨コマンド:

```bash
git fetch --all --prune
git status --short
git rev-parse main
git rev-parse origin/main
git merge-base --is-ancestor 1fbcb3ea804f965b8f262284573f4f4d42dc2411 origin/main
git branch -r --contains 1fbcb3ea804f965b8f262284573f4f4d42dc2411
```

### LV-04 現行テストの回帰確認

パッケージ構成を確認し、リポジトリで正規に使われているコマンドを実行する。少なくとも以下を対象とする。

- Apollo単体テスト
- 3Dモデル受け渡しテスト
- 型チェック
- lint
- production build
- backend/IF3関連テスト（該当する場合）

候補コマンドは実際の `package.json`、README、CI設定を確認して確定する。推測したコマンドをそのまま実行しない。

結果には以下を記録する。

- 実行コマンド
- exit code
- PASS/FAIL件数
- 警告
- 既知不具合との関係
- 再現手順

### LV-05 3D表示の非回帰確認

確認事項:

- Apollo専用画面で床版・主桁等のソリッドが表示されること
- メイン画面でも骨組線だけでなくソリッドモデルが表示されること
- 表示切替、選択、カメラ、STL出力等の既存機能を壊していないこと
- 3D描画用データと設計用データを誤って同一視していないこと

可能であればスクリーンショットと操作手順を保存する。

### LV-06 マニュアル対応表の確認

次の機能群について、アップロード済みAPOLLOマニュアルと計画文書を突合する。

- RC床版
- 格子解析
- 主桁断面
- 添接
- たわみ・剛比・キャンバー
- 横桁・対傾構・横構・斜材
- 支点上・中間・水平補剛材
- 鋼重
- 疲労
- 自動製図
- 計算書・照査一覧

確認事項:

- 計画漏れ
- 合成／非合成の混同
- APOLLO固有ファイル形式への過剰な互換性主張
- 製作図と設計一般図の混同
- 計算書、図面、材料集計のデータ依存関係

### LV-07 非合成床版と接合要素の確認

確認事項:

- RC床版を主桁断面剛性へ加算しないこと
- 合成桁のせん断流を用いたスタッド設計をPhase 1へ混入させないこと
- 必要な接合要素は `deckAnchorage` 等の別概念として扱うこと
- 採用基準がない状態で本数、間隔、耐力を自動決定しないこと
