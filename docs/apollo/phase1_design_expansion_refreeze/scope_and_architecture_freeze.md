# Apollo Phase 1 設計機能拡張 — 調査・設計再凍結

**Status:** FROZEN_FOR_REVIEW  
**Date:** 2026-08-01  
**Baseline:** `1fbcb3ea804f965b8f262284573f4f4d42dc2411`  
**対象:** 非合成RC床版鋼鈑桁橋（多主桁）  
**実装許可:** 本文書単独では付与しない

## 1. 再凍結の目的

3D表示の完成を前提に、Apollo Phase 1を「形状表示」から「設計データ、構造解析、部材照査、図面、計算書が追跡可能な設計システム」へ拡張するため、対象範囲とアーキテクチャを再凍結する。

本フェーズでは、旧APOLLO SuperDesigner / SuperDrawingの機能構成を参考にするが、旧製品の内部実装、既定値、式、判定値をそのまま正解として移植しない。採用基準、材料定数、荷重、許容値、抵抗値、疲労等級、溶接・ボルト条件は、正本資料と決定記録が揃うまで `NOT_AUTHORIZED` とする。

## 2. 対象範囲

### 2.1 Phase 1で対象とする橋梁形式

- 直橋
- 単純桁を初期対象とする
- 等桁高
- 非合成RC床版鋼鈑桁橋
- 多主桁
- 主桁本数は既存Phase 1境界を維持する
- 固定・可動支承の構造定義
- RC床版、舗装、ハンチ
- 中間横桁、端横桁、支点上横桁
- 対傾構、上横構、下横構、斜材
- 主桁補剛材
- 主桁添接
- 鋼重、たわみ・剛比、疲労のデータ境界
- 標準断面、側面構成、配置図、計算書の生成基盤

### 2.2 Phase 1で対象外とするもの

- 合成桁としての床版有効幅・合成断面計算
- 床版を主桁断面剛性へ加算する処理
- 曲線桁、拡幅桁、斜橋、変桁高
- 箱桁、鋼床版、PC床版
- 複数径間連続桁
- 製作詳細図の完全自動生成
- 任意形式の架設検討
- 道示等からの自動既定値投入
- 根拠未採択の数値照査
- 旧APOLLOとの数値同値保証

## 3. 非合成床版とスタッドの扱い

### 3.1 凍結事項

- `compositeAction = false`
- RC床版は主桁の曲げ剛性、断面係数、応力度算定へ加算しない
- 合成桁用のずれ止め設計をPhase 1へ混入させない
- 床版と上フランジ間の接合要素が必要な場合は、合成作用とは独立した `DeckAnchorage` として定義する
- `DeckAnchorage` の目的、必要性、照査方法は採用基準が決定するまで `NOT_AUTHORIZED`

### 3.2 データ上の区別

- `compositeShearConnector`: Phase 1では禁止
- `deckAnchorage`: 定義可能、数値照査は未許可
- `temporaryErectionConnector`: 将来拡張
- `upliftRestraint`: 将来拡張

## 4. 設計ワークフロー

1. 線形・支点・主桁配置を確定
2. 床版、舗装、ハンチ、片持部を定義
3. 横桁、対傾構、横構、支承を配置
4. 材料候補と断面候補を登録
5. 死荷重、活荷重その他荷重を定義
6. 解析モデルを生成
7. 構造解析を実行
8. 解析結果を設計部材へ割り当て
9. 主桁断面、床版、床組、補剛材、添接を照査
10. 鋼重を更新
11. 必要に応じて再解析
12. たわみ・剛比、疲労、照査一覧を確認
13. 標準断面、配置図、計算書を出力

## 5. アーキテクチャ境界

### 5.1 正本モデル

```text
BridgeSuperstructureDesignDocument
  ├─ ProjectAndGovernance
  ├─ GeometryModel
  ├─ StructuralDesignModel
  ├─ LoadModel
  ├─ AnalysisBinding
  ├─ DesignCheckModel
  ├─ DrawingModel
  ├─ ReportModel
  └─ AuditAndProvenance
```

### 5.2 GeometryModel

保持するもの:

- 道路・橋梁中心線参照
- 支間、支承線、桁端
- 主桁中心線
- 横桁線、対傾構位置、横構パネル
- 床版外形、片持長、ハンチ形状
- 3D表示に必要な形状パラメータ

保持しないもの:

- 設計照査結果
- 解析結果
- 図面固有の文字・寸法配置

### 5.3 StructuralDesignModel

主要エンティティ:

- `MainGirder`
- `GirderSectionSegment`
- `RcDeck`
- `Haunch`
- `CrossBeam`
- `EndCrossBeam`
- `SupportCrossBeam`
- `SwayBracing`
- `LateralBracing`
- `BraceMember`
- `Bearing`
- `Stiffener`
- `Splice`
- `DeckAnchorage`

各エンティティは次を必須とする。

- stable ID
- revision
- source / provenance
- geometry reference
- analysis member mapping
- design status
- adoption status

### 5.4 AnalysisModel

解析モデルは設計モデルから派生させる。

- 節点
- 部材
- 支点条件
- 断面剛性
- 材料
- 荷重ケース
- 荷重組合せ
- 出力要求

3D表示用メッシュを解析モデルの正本にしない。描画モデルと解析モデルは共通IDで対応付ける。

### 5.5 DesignCheckModel

共通判定状態:

- `NOT_AUTHORIZED`
- `INCOMPLETE`
- `READY`
- `RUNNING`
- `OK`
- `NG`
- `WARNING`
- `STALE`
- `ERROR`

各照査結果は次を保持する。

- 対象ID
- 使用入力revision
- 使用解析結果checksum
- 採用基準・決定ID
- 計算式ID
- 入力値
- 中間値
- 判定値
- 利用率
- 判定
- 警告・適用外理由

### 6.2 RC床版

- 舗装厚
- かぶり
- 主鉄筋・配力鉄筋
- 片持床版

- 照査横断位置

### 6.3 床組

- 横桁断面力の割当
- 横桁断面
- 横桁添接
- 横桁補剛材
- 対傾構、横構、斜材
- グルーピング
- 有効長、細長比等の照査インターフェース
- 溶接方向、連結形式

### 6.4 主桁補剛材

- 支点上補剛材
- 中間垂直補剛材
- 水平補剛材
- 格点補剛材

### 6.5 添接

- 上フランジ
- 下フランジ
- 腹板
- ボルト径、等級、本数

- 添接板

### 6.6 鋼重

- 断面決定後鋼重

- 再解析要求判定

## 7. 3D表示との統合

3D表示は次の役割を持つ。

- 部材選択
- 設計エンティティへのナビゲーション
- 入力不足、NG、STALEの可視化
- 断面・材質・グループの確認
- 図面対象部材の選択

3D表示だけから設計成立を判定しない。表示可能と設計可能を分離する。

## 8. 図面アーキテクチャ

### 8.1 Phase 1図面

- 標準断面図
- 主桁側面構成図
- 主桁断面変化表
- 横桁・対傾構配置図
- 横構配置図
- 支点部断面図
- 補剛材配置図
- 添接概要図
- キャンバー図
- 部材表

### 8.2 生成階層

```text
Design Model
  -> Drawing Semantic Model
  -> SVG / Canvas preview
  -> DXF or other exchange output
  -> PDF sheet output
```

図面プレビューと正式図面出力を区別する。寸法、尺度、レイヤ、文字、線種、用紙、改訂欄はDrawing Modelで管理する。

## 9. 計算書アーキテクチャ

```text
ReportModel
  ├─ 設計条件
  ├─ 構造概要
  ├─ 材料
  ├─ 荷重
  ├─ 解析条件・結果
  ├─ RC床版
  ├─ 主桁
  ├─ 床組
  ├─ 補剛材
  ├─ 添接
  ├─ たわみ・剛比
  ├─ 疲労
  ├─ 鋼重
  ├─ 図面
  └─ 監査記録
```

画面HTMLを直接印刷して正式計算書にしない。計算結果と根拠を構造化してからPDF等へ変換する。

## 10. 変更・再解析・STALE規則

以下の変更は解析結果をSTALEにする。

- 主桁位置、支間、支点条件
- 主桁断面・材料・剛性
- 横桁、対傾構、横構配置または断面
- 荷重
- 床版・舗装・ハンチ重量
- 鋼重更新

以下は原則として図面のみSTALEとする。

- 文字位置
- 寸法線配置
- 表示尺度
- 図枠

## 11. 禁止事項

- 出典不明の既定値を正式値として自動入力しない
- マニュアル画面の例示値を設計標準値として採用しない
- 未採択式で `OK` を返さない
- 解析結果と異なるrevisionの設計照査を有効扱いしない
- 3D表示用寸法を解析・計算の正本へ暗黙流用しない
- 非合成桁に合成断面計算を混入させない
- 図面プレビューを製作図として表示しない

## 12. 完了条件

本再凍結は次を満たしたとき完了候補とする。

- 本文書、実装順序、マニュアル対応表が揃う
- 既存AP-00〜AP-18との整合が説明される
- 未確定数値項目が明示される
- 3D、解析、設計、図面、計算書の責務境界が明示される
- ローカル検証計画が保存される
- GitHub上の文書差分検査が完了する
- 必要なローカル検証結果が保存される
