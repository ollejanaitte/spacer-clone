4. **荷重係数・組合せ**（VR-R7-I-001/002）
5. **RC床版**（VR-R7-III-001..004）
6. **横桁・補剛材**（VR-R7-II-009/010）
7. **添接・支承**（VR-R7-II-011、VR-R7-V-001/002）
8. **疲労**は OUT_OF_SCOPE 維持（VR-R7-II-012 はデータ境界のみ）

## 記入・判定方法

1. 対象 PDF を開き、該当ページの条項・表・式を目視確認する
2. 「ページ」「条項・表番号」「記録する情報」欄に、**確認した実際の値・式・条件**を記載する
3. 正誤表（2026-03-31）で修正された項目かどうかを併記する
4. 「確認結果」欄: `CONFIRMED`（採択可）/ `CONFIRMED_WITH_ERRATA`（正誤表反映後採択可）/ `MISMATCH`（既存レジスタと不一致）/ `NOT_FOUND`（対象条項なし）
5. 「証跡保存先」欄に、目視確認のスクリーンショット・メモ・OCR の保存場所を記録する
6. 確認完了後、01_blocker_resolution_register.csv の該当行と 08_numeric_authorization_gate.md の該当セルを DEC-ID 付きで更新する
