## 2. 相互照合の流れ（X1で確立するチェーン）

```
道路構造令の規定（区分・設計速度・最小R等）
    ↓ ルールエンジン候補（RULE-01〜23）
JIP-LINERの入力・計算機能
    ↓ マニュアル＋サンプル計算書
実案件の線形計算書（西知多道路・東海JCT）
    ↓ 測点・R・A・片勾配・縦断
道路設計図（平面線形・標準横断）
    ↓
橋梁線形・桁配置・上部工資料（道示・鋼鈑桁橋・APOLLO）
```

## 3. ルールエンジン候補との対応

`RESEARCH_PRIORITY.csv` の P0 資産から、RULE-01（道路区分）〜RULE-23（例外）の
入力値・要求値・許容範囲・警告条件を抽出する。詳細は道路構造令フェーズ成果物
（`road-structure-ordinance/RULE_ENGINE_CANDIDATES.csv`）を参照。

## 4. サンプル案件との照合関係

- 実案件（西知多道路）の値（R=400/500/1900、A=450）を道路構造令の規定と照合。
- LINERサンプル計算書の入力/出力とJIP-LINERマニュアルの機能仕様を照合。
- 鋼鈑桁橋_設計計算例の計算値と道示の照査式を照合。
