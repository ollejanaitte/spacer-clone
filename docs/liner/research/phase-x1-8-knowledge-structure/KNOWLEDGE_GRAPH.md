# KNOWLEDGE_GRAPH — 知識グラフ

## 中心フロー

```
SOURCE_DOCUMENT
  ↓ DEFINED_BY
STANDARD_RULE
  ├── APPLIES_WHEN → RULE_CONDITION
  ├── CONSTRAINS → DESIGN_PARAMETER
  ├── LOOKS_UP → LOOKUP_TABLE
  └── CALCULATED_BY → FORMULA → PRODUCES → CALCULATED_VALUE

DESIGN_PARAMETER
  ├── ADOPTED_FROM → ADOPTED_VALUE
  │   └── CROSS_CHECKED_BY → STANDARD_RULE
  ├── DERIVED_FROM → ADOPTED_VALUE
  └── DEPENDS_ON → DESIGN_PARAMETER

INPUT_VALUE → NORMALIZES_TO → DESIGN_PARAMETER

ALIGNMENT
  ├── BELONGS_TO → ALIGNMENT_ELEMENT
  ├── LOCATED_AT → STATION → COORDINATE
  └── MAPS_TO → LINER_MODULE

ALIGNMENT → FEEDS → ROAD_BRIDGE_INTERFACE
  └── ROAD_TO_BRIDGE → PIER

ADOPTED_VALUE → REPORTED_IN → REPORT_SECTION
DRAWING_VIEW → DRAWN_IN → DRAWING
DESIGN_PARAMETER → VALIDATED_BY → VALIDATION → CONTROLS → WARNING
APOLLO_CANDIDATE → APOLLO_MAPS_TO → GIRDER_LINE
```

## 主要Entity間のRelation

| From | Relation | To | 意味 |
|------|----------|----|------|
| STANDARD_RULE | CONSTRAINS | DESIGN_PARAMETER | 基準値が設計値を制約 |
| FORMULA | PRODUCES | CALCULATED_VALUE | 式が計算値を生成 |
| ADOPTED_VALUE | CROSS_CHECKED_BY | STANDARD_RULE | 採用値が基準で照査 |
| ROAD_BRIDGE_INTERFACE | ROAD_TO_BRIDGE | PIER | Interfaceが橋脚を生成 |
| APOLLO_CANDIDATE | APOLLO_MAPS_TO | GIRDER_LINE | Candidateが主桁にマップ |
