# RULE_ENGINE_BOUNDARY — Rule Engine境界

## 入力（Rule Engineが受け取る）
- 道路種級・設計速度・設計車両
- 曲線半径・片勾配・拡幅量
- 縦断勾配・縦断曲線半径
- 横断勾配・合成勾配
- 視距・車線幅員・路肩幅員・中央帯幅員

## 出力（Rule Engineが生成する）
- 要求値（最小値・最大値・推奨値）
- 照査結果（PASS/WARNING/ERROR）
- 例外条件の有無
- 警告メッセージ・エラーコード

## 非責務（Rule Engineが行わない）
- 線形座標の計算
- 測点の算出
- 座標変換
- 図面生成
- 橋梁構造計算
