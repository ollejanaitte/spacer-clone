# 外部公開情報レビュー（JIP-LINER公式）

根拠: JIPテクノサイエンス公式サイト・カタログ PDF（https://www.jip-ts.co.jp/product_service/jip_liner/, jiplinercat_202510/202404/202308.pdf）を websearch で取得。分類: FACT(公式)。

## 1. JIP-LINER 公式の位置づけ

- 「線形座標計算システム」として、**直橋から複雑なランプを含む形状の橋梁、さらに一般道路の座標計算**に対応。
- 用途: 橋梁・道路の線形予備計算、座標計算、ハンチ計算、舗装厚計算、線形図作成。
- 長年の使用実績（実務標準としての地位）。

## 2. 公式プログラム機能（カタログ記載）

| プログラム | 公式説明（要約） |
|---|---|
| LINER | 要素変化点の座標・要素長、橋脚・横桁との交点座標、縦横断勾配・立ち上がりから計画高を算出 |
| APLINE | IP点を指定したすりつけ・非常駐車帯の設定など、ライン確定の予備計算 |
| HAUNCH | 鋼橋の主桁ハンチ量・桁天端高。舗装厚・床版厚を考慮し、直線変化・1次変化など様々な計算方法 |
| HOSO | コンクリート橋の主桁舗装厚・桁天端高。舗装厚・体積を最小にする平面の自動決定、キャンバー考慮 |
| GDRAW | 平面図と座標テーブルを作成 |
| GVIEWX | 平面要素図・橋脚設置図・縦断線形図・横断線形図・座標変換方法の図面 |
| FOOTING | 下部工フーチング図・フーチング座標図 |
| GCROSS | 主桁の形状まで考慮した断面図 |
| MDVIEWER | 線形マスタファイルから抽出し、座標テキスト出力・橋面の面積計算・3次元DXF出力 |

→ Phase1 棚卸しと一致（GVIEW は公式名 GVIEWX と確認）。

## 3. 連動エコシステム（公式）

- **線形マスターファイル**を介して:
  - JIP-SPACER（任意形立体骨組の断面力解析システム）
  - HyBRIDGE/設計（鋼桁橋設計システム）
  - HyBRIDGE/DRAFT-B（鋼箱桁橋製図システム）
  - HyBRIDGE/DRAFT-I（鋼鈑桁橋製図システム）
- → 現行 spacer-clone の「LINER→Frame/解析/3D/図面」連動は、この JIP エコシステムに相当する位置づけ。

## 4. 公式カタログの操作・出力の特徴

- 補助ダイアログによるデータ作成 + テキスト形式の直接編集（両対応）
- **編集した桁配置データは画面下半分の平面図ですぐ確認**（ライブプレビュー）
- 視覚的に確認できる平面図によりデータ作成ミスを防止
- 任意測点での断面図描画で幅員確認
- 座標テーブル（平面図・線形計算・ハンチ/舗装厚計算を考慮）
- 出力: テキスト・カンマ区切りテキスト(CSV)・DXF図面・線形一般図
- 計算結果の他、**チェックリスト・基準線に着目した座標・単距離の出力**

→ 「ライブ平面図確認」「テキスト+補助ダイアログ」「CSV/DXF」は本調査の UX 構想（Phase5/6）と整合する。

## 6. 本調査への示唆

1. **実務標準性**: JIP-LINER の機能セット（座標計算→計画高→ハンチ/舗装→図面）は現行 spacer-clone の Road モジュールと構造一致。差分は主に「曲線橋骨格・ハンチ全型・連動（上部工/図面）・UX」。
2. **ライセンス/価格**: 有償実務ツール。現行はオープンソース Web/Electron 実装として、同一機能を低コストで提供できる潜在価値。
3. **連動標準**: JIP はマスターファイルで線形→解析/製図に連動。現行は sourceRevision+Frame/STL/DXF で同等を実現。連動契約（IF）の整備が望まれる。
4. **UXの裏付け**: 「ライブ平面図」「補助ダイアログ+テキスト編集」は Phase5/6 の2Dエディタ構想の実務妥当性を裏付ける。
