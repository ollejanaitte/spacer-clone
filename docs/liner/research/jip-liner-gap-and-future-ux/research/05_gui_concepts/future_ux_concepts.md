# 追加機能・将来UX構想

## 1. 設計原則

1. **データは一つの情報源（Single Source of Truth）** —— 平面・縦断・横断・橋梁骨格・派生計算（LDIST/HAUNCH/HOSO）はすべて RoadDesignDocument 上の定義から計算。図面・帳票・3Dは再生成（DrawingDocument を永続化しない現行方針を維持）。
2. **入力は常に検証** —— パイプライン診断を逐次実行し、エラーを即時表示（fail-closed を維持）。
3. **可視化は「いつでも・どこでも」** —— 2D 平面図・縦断図・断面図を常時プレビューし、データ編集と同期。
4. **実務書式を尊重** —— JIP-LINER の帳票・実設計例の形式と整合する出力（単位・表組み・順序）。
5. **現代のGUIを適用** —— テキストファイル主導の JIP-LINER から、図面直編集+インスペクタのモダンUIへ。

## 2. 追加機能一覧（Phase3 の差分を受けた実装アイテム）

### 2.1 線形・測点
- [F1] 拡幅（1次/4次）計算の実装（現在は型定義のみ）—— 曲線橋の車線拡幅に必須
- [F2] 接続/分岐（ランプ）対応のデータモデル拡張（現行は単一 active alignment）
- [F3] 測点有効範囲（ランプ・ブレーキ）の正規化
- [F4] 平行線・直角平行の入力支援（Offset の拡張）

### 2.2 高さ・橋梁骨格
- [F5] ハンチ用 G 高さ系（W/WG, WA/WAG, WB/WBG）の追加
- [F6] ピア設定方式の拡張（2点結ぶ・平行・角度・基準セクション）
- [F7] スパン簡易入力（参照ピア→セクション間隔の生成）
- [F8] セクションS×主桁G の格点モデル（S×G 交差を正規入力として）
- [F9] 主桁Gの円弧桁/折れ桁定義
- [F10] 小標系（TRAN）対応

### 2.3 派生計算
- [F11] ハンチ JIP 型の残り（3:一定, 11:最小2乗, 13:比例, 15:キャンバー円弧, 16:対角線, 17:全入力）と基準桁型（4,5,10）
- [F12] 舗装厚の照査（最小厚）UI
- [F13] LDIST 出力の実設計例（AG1/AG2 の支間長・格間長）との突合検証（ゴールデン化）

### 2.4 図面
- [F14] 交角描画
- [F15] 寸法線の自動/手動規則（ライン間・セクション間）
- [F16] 座標テーブルの項目数・精度の公式化
- [F17] プロファイルのバンド完成（地面データの入力方法を確定）

### 2.5 検証・品質
- [F18] 実JIP-LINER出力（SRC-004）・実設計例（SRC-005）をゴールデンフィクスチャとして取り込み、数値を突合
- [F19] Importer サンプルの補間値（C1-C17/GE2）を PDF 実値へ置換

## 3. UX 構想（2Dエディタ / 画面構成）

### 3.1 全体構成（JIP-LINER の「1ファイル・1画面」からモダン化）

```text
┌─────────────────────────────────────────────────────────┐
│ メニューバー / タブ（line | station | height | ... ）       │
├───────────────────────┬─────────────────────────────────┤
│ 左：インスペクタ      │ 中央：2Dキャンバス                │
│  - ライン一覧         │  平面図（ライブ）                  │
│  - 選択要素の属性     │  縦断図（ライブ）                  │
│  - パラメータ入力     │  横断図（ライブ）                  │
├───────────────────────┴─────────────────────────────────┤
│ 下部：ステータスバー / 診断 / パイプラインメッセージ        │
└─────────────────────────────────────────────────────────┘
```

- **タブ**は現行の `line/station/height/vertical/crossSection/utilities/review` を維持（JIP-LINER データ順）。
- 各タブに**ライブプレビュー**を常設（平面/縦断/横断をタブ連動）。
- **プログレスガイド**: 「線形→測点→高さ→ピア→スパン→出力」の段取りを上部に表示し、未入力ステップを案内。

### 3.2 2D 平面エディタ（Phase6 詳細）
- 要素を点・線として描画し、**ドラッグで移動・伸縮**、**スナップ**（端点/交点/クロソイド接点）、**寸法入力**（R, A, L, 方位角）に対応。
- クリックで要素選択 → インスペクタに属性表示 → 編集。
- 平行線/拡幅を「オフセットツール」で指定（距離+基準線）。
- 主桁G/セクションSを平面上に可視化し、格点をハイライト。

### 3.3 縦断エディタ
- クラウン・勾配・パラボラを視覚化。変化点をドラッグ編集。
- ハンチ/舗装厚を断面高さとして重ね表示。

### 3.4 エラー・検証
- パイプライン診断を常時実行し、**エラーはキャンバス上の該当要素にインライン表示**。
- fail-closed を維持しつつ、修正を誘導（「ピア K10 がライン L200 の範囲外」→ 修正ツールを提案）。

## 4. 優先度の考え方

- **実務で使う頻度**（曲線橋・拡幅・ハンチ全型・交角描画）を高優先。
- **検証**（F18/F19）は数値の信頼性に関わるため最優先の一つ（現行ゴールデンの外部突合）。
- **接続/分岐**は構造的拡張が大きく、Phase8 の特殊線形として後段。

## 5. 現代の代替（JIP-LINER 再現ではなく現代化）

| JIP-LINER のやり方 | 現代の代替 |
|---|---|
| 1テキストファイルに全データ | RoadDesignDocument（永続化・スキーマ管理） |
| バッチで計算・エラー | 逐次計算・インライン診断 |
| テキスト入力+帳票 | GUI+ライブプレビュー+帳票 |
| 図面は PLOTFILE/DXF | 常時プレビュー+DXF export |
| マスタファイルで連動 | sourceRevision による stale 管理 |
| バックアップ/復元（LIM） | autosave・バージョン管理 |
