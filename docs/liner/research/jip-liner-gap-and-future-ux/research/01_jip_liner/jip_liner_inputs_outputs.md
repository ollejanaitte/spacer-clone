# JIP-LINER 入力・出力

根拠: マニュアル(§1.6, §2.2-2.3, §5-8) + サンプルLINER計算書(SRC-004)。分類: FACT(マニュアル/実データ)/INFERENCE。

## 入力

| 項目 | 内容 |
|---|---|
| データファイル | 単一 `.LIN`（全プログラムデータを `##### PROGRAM` ブロックで同居） |
| コマンド | GUIメニュー / コンソール `liner` → FILENAME入力 → RUN NO |
| データ種類 | ラインデータ、測点、縦断・横断・断面高さ、ピア、スパン、出力、座標変換 |
| 帳票表示 | TV（帳票ビューワ）。Textviewへ切替可 |
| 予備計算 | APLINE（IP線形・非常駐車帯・切断・接続）、交点/距離/法線の予備計算 |
| 単位 | 長さm、角度度-分-秒（例 194-53-11.4）、勾配%（縦断・横断） |

## 出力（§2.3）

| 拡張子 | プログラム | 内容 |
|---|---|---|
| LL1 | LINER | 構文チェック |
| LL2 | LINER | 線形計算結果 |
| MDK | LINER | マスタファイル（$SET MASTER時） |
| CHI | LINER | 高さチェックリスト（$SET CHKHI時） |
| _L.CSV | LINER | 線形計算結果（$SET CSV時） |
| LS1/LS2 | LDIST | 構文/格点間距離・張出し長 |
| HL1/HL2 | HAUNCH | 構文/ハンチ結果 |
| HS1/HS2 | HOSO | 構文/舗装厚結果 |
| _S.CSV | HOSO | 舗装厚結果（オプション時） |
| GL1 | GDRAW | 構文 |
| LIM | 全 | データのバックアップ |
| 固定名 | | チェックリスト.txt、PLOTFILE.1/.2（図面）、DXF |

- テキスト形式（マスタ以外）はテキストエディタで可読
- PLOTFILE→DXF変換はPVで実施。実寸はPVのDXF変換時

## 出力帳票（サンプル計算書・設計計算例から実形式）

### 1. 入力データ（帳票先頭）
- TITLE、LINE DATA、STATION DATA、HEIGHT DATA、PIER DATA、SPAN DATA、OUTPUT DATA の原文出力

### 2. 平面線形（ラインごと）
- 要素番号・要素種(円/クロソイド/直線)
- 要素長、曲率半径、曲率中心方向(左右)、パラメータ、始点/終点曲率半径
- 始点/終点のX座標・Ｙ座標・方位角・測点、曲率中心座標

### 3. 縦断線形・横断線形
- 要素番号・測点・クラウン高/勾配・緩和曲線長・前勾配・後勾配・曲線長（縦断）
- 測点・勾配・緩和曲線長・曲線長（横断）

### 4. 橋梁横断面（大座標/小座標）
- 径間名、横断面番号・名称、方位角
- 橋軸線ごと: Ｘ座標、Ｙ座標、計画高、横断勾配、単距離、累加距離、単幅、累加幅、交角、測点
- 出力対象: 出力指定(PRTL/PRTS)で指定したライン/セクション

### 5. 主桁格点・支間（設計計算例）
- 主桁支間長（主桁別・径間別）
- 主桁格間長（格間別・主桁別）
- 横断間隔長（歩車道境界〜主桁間）
- 主桁腹板高
- 主桁格点座標（横断別・主桁別 X/Y）
- 床版張出し長（法線方向・左右）
- 曲率（主桁中心・格間別）

## 連動・外部
- HAUNCH/HOSO/GDRAWはLINER結果（マスタファイル）を参照して計算・描画
- MDSKOUTでMightyBridge連動ファイル、MDVIEWERで3次元DXF
- 「計算」メニューのテキスト出力で結果を他アプリ連動可
