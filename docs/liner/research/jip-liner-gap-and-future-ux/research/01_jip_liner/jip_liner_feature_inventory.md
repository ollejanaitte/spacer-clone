# JIP-LINER 機能棚卸し

- 根拠: `sources/manuals/JIP-LINER_マニュアル.pdf`(P183, SRC-001)、サンプルLINER計算書(SRC-004)。ページ/節はマニュアル頁。先行研究(Scope_of_Work)も一部参照。
- 分類記号: PARITY_REQUIRED / PARITY_USEFUL / MODERNIZE / REPLACE_WITH_BETTER_WORKFLOW / LEGACY_ONLY / OUT_OF_SCOPE / UNKNOWN
- 棚卸しは画面名でなく「設計データ・計算・出力・検証」単位で分解する。

## 1. システム・ファイル・運用（§1-4, §9, §11）

### プログラム構成（§1.2, §1.5）
- **LINER**: 線形計算（平面・縦断・横断・ピア・スパン・格点）
- **HAUNCH**: ハンチ計算
- **HOSO**: 舗装厚計算
- **GDRAW**: 平面図・座標テーブル・図面/DXF
- **LDIST**: 格点間距離・張り出し長の出力
- **MDSKOUT**: MightyBridge連動用ファイル作成
- **APLINE**: 予備計算（IP線形等の高度ライン）
- **LTOOL**: 線形情報出力
- **GVIEW**: 線形一般図
- **FOOTING**: フーチング図
- **MDVIEWER**: 橋面面積計算・3次元DXF出力
- **GCROSS**: 標準断面図
- 分類: メイン5(LINER/HAUNCH/PM/ROAD/HAUNCH) を1テキストファイルで合成管理（`##### LINER`..`END`）。図面(GDRAW)のみ複数データ可。

### 制約・規模（§1.1）
| 項目 | 上限 |
|---|---|
| ライン数 | 100 |
| 要素数 | 100 |
| ステーション数 | 50種 |
| 縦断/横断/断面高さグループ | 各50 |
| 変更断面 | 50 |
| ピア数 | 500 |
| スパン数 | 90 |
| ライン+縦桁G/スパン | 100 |
| 横桁S/スパン | 500 |
| ストアデータ(GG,SS) | 50 |
| 折れ点 | 50 |

### ファイル構成（§2.3）
- 入力: 単一 `.LIN`（全プログラムデータを1ファイル）
- 出力(拡張子固定): LL1(構文), LL2(線形結果), MDK(マスタ), CHI(高さチェックリスト), _L.CSV, LS1/LS2(LDIST), HL1/HL2(HAUNCH), HS1/HS2(HOSO), _S.CSV, GL1(GDRAW), LIM(バックアップ)
- 固定名: チェックリスト.txt、PLOTFILE.1/.2、DXF
- バックアップ/復元: LIM自動バックアップ(描画前)、テンポラリ(_SIMPLE*.tmp)からの手動復元

### 実行形態
- GUI編集画面 + テキスト画面 + 作図画面
- コンソール実行: 「liner」コマンドでFILENAME入力、RUN NO でコマンド実行（§1.6）
- TV(帳票ビューワ)、PV(プロットファイルビューワ、PLOT→DXF変換可)
- 環境設定: パス・環境変数(LINER=...)、HyBENV(Si.bat/Editor.bat)（§1.7）

### 分類
- メイン5プログラム(LINER,HAUNCH,ROAD,PMD,GDRAW) → 現行の機能部署。
- 帳票/DXF/PLOTを一元的に扱う。現行は、LINER相当+GDRAWに取り組んでおり、他のオプションプログラム(APLINE,MDSKOUT,GVIEW,FOOTING,MDVIEWER,GCROSS)は未実装と判断 → PARITY_USEFUL/OUT_OF_SCOPE。

## 2. ライン・平面線形（§5.2）

- ライン一覧（ライン記号/名称、有効/無効、設定方法、基準ライン記号）
- 要素の種類: 直線(S)、円(R)、クロソイド(A)
- 入力方法:
  (1) 始終点+パラメータ（行単位）
  (2) 延長距離+パラメータ（ADD, L=..., R=..., A=..., BR/ER）
  (3) 基準要素を平行(//)/(|| 直角平行)・拡幅(1次/4次)移動
- 設定条件記号: BR=始点半径, ER=終点半径（卵形は両方指定、一致はエラー）
- 認証: 確認図（平面図・断面図）でのエラーリスト、`////`(平行)と`||`(直角平行)の区別
- 平行線の要素変化点ズレへの対処（|TECHNIQUE")
- 要素表（帳票出力対象ライン指定）
- ライン始点/終点、方位角、曲率、要素長、（測点は§5.3）

### 拡幅・平行
- 平行線、拡幅線(1次/4次)、断面形状(車線別ライン/幅員)の簡易設定
- 拡幅線を含む断面形状の作成手順
- 拡幅は「要素より自由な拡幅」はAPLINEのみ対応（LINER自身はNG）

### 分類
- 直線/円/クロソイド(双曲線)=(要素・パラメータ) → PARITY_REQUIRED（現行に実装あり、機能差はGUT/精密の入力方法）
- 要素入力3方式(1)(2)(3) → PARITY_USEFUL
- 拡幅(1次/4次) → 現行は「型定義のみ」で現状PARTIAL → PARITY_REQUIRED（曲線橋では必須）
- 断面形状からの高さデータ自動生成 → PARITY_USEFUL
- APLINE相当(IP線形/非常駐車帯/切断接合) → PARITY_USEFUL/将来

## 3. 測点設定（§5.3）

- 測点データ: 測点を持つライン、要素番号、始点測点(例12+34.5/-12-34.5)、ピッチ(進行方向と正/負)
- 測点の有効範囲(始点側/終点側)、変化点情報、計算対象外ライン、コメント
- データ順優先（後データ優先）、Ctrl+↑/↓ 順序変更
- ランプ/分岐で測点を2つ以上に分ける（有効範囲を使い分け）
- ブレーキ(里程折れ)では前後で測点体系を変える
- 出力: 要素表ではSTATION DATAのNAME使用

### 分類
- 測点体系・区切・ピッチ・算出 → 現行パイプラインで実装済み。ただし手の込んだ「測点の有効範囲」をJIP互換まで実現しているかは要現行監査(PARTIAL)
- ランプ分岐の測点説明 → 将来

## 4. 高さデータ（§5.4）

3system: 縦断勾配(PH)、横断勾配(GR)、断面高さ設定(W/WG・WA/WAG・WB/WBG)

- 縦断勾配: 測点データ対応、変化点(測点・高さ・VCL)、クラウン、測点有効範囲、帳票出力、予備計算(任意測点の計画高)、要素変化点の測点参照
- 横断勾配: 変化点(測点・横断勾配・VCL)、パラボラ横断はVCLに"P"、予備計算、正負反転(GR(-n))
- 断面高さ設定:
   - 標準形(W,WG): PHラインの測点で高さ計算
   - 簡易形(WA,WAG): PHラインのABが測点ラインに合うよう補正
   - 平均計算(WB,WBG): 2条のライン高さ+立ち上がりから基準で平均
   - 変化点(始点側ライン/終点側ライン/立ち上がり量/横断勾配/法線ライン)、計算対象外ライン
   - G付き(WG/WAG/WBG)はハンチ用で帳票非出力・マスタにのみ
- 高さデータは50グループまで

### 分類
- 縦断勾配/横断勾配/断面高さ → PARITY_REQUIRED（現行はvertical/crossSectionタブで実装。検証は後述）
- 標準形(W)/簡易形(WA)/平均(WB) → PARITY_REQUIRED（現行はZ Mergeと断面高さ）

## 5. ピア設定（§5.5）

- ピア中心線・斜角・橋軸との関係
- 設置方法(補助ダイアログ等):
   1. ライン始点からの距離(K1-K3: 23.4,2@15.0 ON L1) ※交角指定時は2データ(SET)
   2. 既存ピアと平行(//)
   3. 距離と方向(FR ... TO ... ON ... //(平行) #(前面))
   4. 2点を結ぶ((L1,K1)*(L5,K2), 座標指定)
   5. 1点を通りラインに垂直(#)
   6. 1点を通りピアと平行(//)
   7. 1点と角度(/123-00-00, 方位角, /80-00-000/L1, 直線に対して)
   8. 要素変化点((L1,1,BE)等)
   9. 測点入力(基準ライン・ピア記号/名称・測点・角度)——簡易入力
- 出力指定(交点の帳票出力): outputピアと口径、幅員表示中心ライン
- チェック表: ライン非存在位置のピアはエラー。交点計算可・法線・2点間距離の予備計算
- 確認図

### 主要なピア配線の構文（サンプル計算書(SRC-004)に実際例あり）
```
K10 : 195.738732 ON L200
K10 : * /90/ L200
K11 : (L200,K10) /90/ L100
K12,K13,K14 : 213.822918,57.5,61.5 ON L100
```

## 5. スパンデータ（§5.6）

- スパン一覧（記号・名称、有効/無効）
- 簡易入力: ①参照ピア選択→②径間ごとのセクション間隔(桁端GE・支承S・横桁C) → テキスト生成
- 桁設定（セクションSと主桁Gの配線）:
   - セクション設定: ピア参照(S1-S6: K1-K6), 既存と平行(//), 距離と方向(FR../ON..#), 複数点を結ぶ(直線/折れ), 1点と方向, 2ライン(主桁)上の点を結ぶ(& G1 & G2), 折れ地
   - 主桁設定: ライン・参照, 既存と平行, 距離と方向, 複数点を結ぶ(直線/折れ桁), 1点と方向, 2セクション上の点を結ぶ(& S1 & S4), 折れ桁, 円弧桁(R=半径 or 3点)
- 出力指定: 出力ライン(主桁)/セクションの名称、幅員中心ライン、一括更新(番号範囲・全・無指定・頭文字)
- 座標変換(小標系): 原点(X軸1点)、座標系
- 確認図
- STORE(GG/SS) / LO専用主桁

### 主桁格点・格間
- セクション(横桁S)と主桁Gの交点が「格点」「格点間距離」(§5.8 LDIST)
- 床版張出し・支承・桁端はスパン簡易入力とLDIST(張り出し長)で出力

## 6. LDIST（格点間距離チェック）（§5.8+）

- スパン一覧（出力対象）
- 格点間距離: 距離計算方法（セクション上の距離直接 or 交角サインを乗「基準ライン指定」）、計算ライン(主桁)名称、計算セクション(全/名称)
- 張り出し長: 左側/右側ライン、計算セクション ⊗ 出力
- 異常検出(FF1/LL1)、出力単位
- 実データ(設計例)では主桁格間長・支間長・横断間隔長の表

## 7. ハンチ計算（§6）

- スパン一覧（対象選択）
- スパン共通入力: 舗装厚+床版厚(全桁一定/方桁)、支点セクション名称
- タイプ(16+17) 各は、2支点/勾配/一定/基準桁勾配/比例/3点・平面/1点+勾配/範囲/3次曲線/基準桁勾配/最小2乗/LINER2離/比例/2点+法線/基準桁3点円弧/対角線/すべて手入力
- 出力項目名称変更(§6.4)
- タイプ8で範囲限定(セクション範囲内のみ計算)

## 8. 舗装厚計算（HOSO）

- スパン一覧、舗装範囲(橋軸方向の左側/右側セクション、橋軸直角方向の上/下側ライン+最小舗装厚、基準桁、リズ量(キャンバー)、最大3段継目)
- 計算タイプ: 自動決定 / 縦断のみ / 横断のみ / 縦断+横断 / 3点指定 / 2点指定
- 舗装厚の照査(各範囲の最小厚)
- 収束が納追い(LINER交点の橋面高で収束)・自動決定はマスタに依存

## 8. 図面作成（GDRAW）（§8）

- 図面一覧(図面データ複数可)、基本データ(描画オプション/scale/用紙/文字サイズ/枠/座標軸)
- スパン構成（車線ごと:基準ライン/左端/右端、セクション引き出し線方向）
- ライン描画(変化点円半径/名称方向/円弧描画/非表示/線種/延長)
- セクション描画(名称方向/非表示/線種/延長・引き出し線)
- 交角描画(半径・対象)
- 座標テーブル(小時、テーブルセルサイズ、3/4/5項目)
- ライン間寸法線(§8.8)
- セクション間寸法線(§8.9)
- 出力: PLOTFILE.1/.2/DXF、帳票(座標テーブル)

## 8. データサンプル（§10）/エラー処理（§11）

- 標準ケースで、新規→ライン(直線)→円→クロソイド→確認→断面形状→高さ(縦断/横断/断面)→ピア(測点入力)→スパン(簡易)→確認→出力指定→LINE計算→帳票
- エラー処理: 構文チェック(LL1)、計算エラー(帳票へ、基準ラインと交点不可、セクション方位とのし等)、警告

## まとめ: JIP-LINERの核となる設計データ項目
1. 平面線形（直/円/クロソイト、拡幅・平行）
2. 測点体系
3. 縦断勾配・横断勾配・断面高さ（+ハンチ用WG系）
4. ピア中心線（斜め・方位角）
5. スパン（セクション=横桁基準、主桁G）
6. 快階構造（橋格点・格間長・張出し長）→ LDIST
7. ハンチ天端（平面/勾配）
8. 舗装厚
9. 図面/DXF（平面図・座標テーブル・寸法線・交角）

上記の「データ項目」は後段のPhase3ギャップと正しく照合するため`jip_liner_feature_inventory.csv`に集約する。
