# JIP-LINER データエンティティ

根拠: マニュアル(§1.5, §2.3, §5-8) + サンプルLINER計算書(SRC-004)の入力データ全文。
エンティティはLINER/HAUNCH/HOSO/GDRAWの各テキストデータブロック単位に整理。

## 1. データ構成（単一 .LIN ファイル）

```text
##### LINER ... END
##### HAUNCH ... END
##### HOSO ... END
##### GDRAW ... END
##### LDIST ... END
```

- LINERデータより前のデータは保存時残存
- HAUNCH/HOSO/LDIST/GDRAWは複数データがあっても最初のデータのみ読込（GDRAWのみ全データ読込）
- 行は最大80文字。継続行は1列目に"C"（最大10行）

## 2. LINER エンティティ

| エンティティ | 記法 | 主要フィールド | 備考 |
|---|---|---|---|
| TITLE | `TITLE : 名称` | 件名 | 帳票見出し |
| LINE DATA | `L100(1)/R : (X,Y) R=1900` | 要素種S/R/A、座標、R/A/BR/ER、平行//・直角||・拡幅(1/4) | 行番号は要素番号。`END`で終点 |
| STATION DATA | `STA(100) : L100 37+18.17 -20 L100-L100` | ライン、始点測点、ピッチ、法線、有効範囲 | 複数データ可 |
| HEIGHT DATA | `PH(5) : STA(500)` / `GR(5) : STA(500)` / `W(5) : PH(5) GR(5) L500 L501-L504` | 縦断(測点/高さ/VCL)、横断(測点/勾配/VCL)、断面(W/WG,WA,WAG,WB,WBG:PH/GR/ライン範囲/変化点) | |
| PIER DATA | `K10 : 195.738732 ON L200` / `K11 : (L200,K10) /90/ L100` | ピア記号K、位置/方向 | 9種類の設定方式 |
| SPAN DATA | `S1,S2,S3,S4 : K11-K14` / `S10 : -0.85 // S1` / `G301 : (G311,S12)*...` | セクションS(横桁/支点)・主桁G | スパンごと |
| OUTPUT DATA | `SPAN : SP5` / `PRTL(...)`, `PRTS`, `TRAN`, `SETTRAN`, `RESETTR` | 出力スパン、座標変換、出力ライン/セクション | |
| 座標変換 | `TRAN : (L500,S1)(L500,S4)(XY)` | 原点、X軸上の1点、座標系 | 小座標系 |

## 4. 派生エンティティ（計算結果）

- 平面線形（要素ごと）: 要素長、曲率半径、曲率中心、始点/終点座標・方位角・測点
- 縦断線形: クラウン高、緩和曲線長、前/後勾配、曲線長
- 横断線形: 勾配、緩和曲線長、曲線長
- 橋梁横断面（大座標/小座標）: 橋軸線(ライン)ごと X座標/Ｙ座標/計画高/横断勾配/単距離/累加距離/単幅/累加幅/交角/測点
- 主桁格点座標、格間長、支間長、張出し長、曲率(主桁中心)、腹板高（設計計算例側の出力）
- マスタファイル(MDK): 後続(HAUNCH/HOSO/GDRAW)が参照する連動データ

## 5. HAUNCH エンティティ（§6）

- スパン一覧（対象）
- スパンごと: 舗装厚+床版厚（一定/主桁ごと）、支点セクション名称
- 計算タイプ(1-17): 計算ライン(主桁)、主桁ごと舗装厚+床版厚、範囲(タイプ8)、出力項目名称
- 出力: ハンチ量/天端高(各格点)

## 6. HOSO エンティティ（§7）

- スパン一覧、舗装範囲（橋軸方向:左右セクション、橋軸直角:上下ライン+最小舗装厚、基準桁、ライズ量）
- 計算タイプ(自動/縦断/横断/縦断横断/3点/2点)
- 出力: 舗装厚（主桁ごと・格点）

## 7. GDRAW エンティティ（§8）

- 図面一覧（タイトル・有効）
- 基本データ（描画スケール/用紙/文字/枠/座標軸/寸法線）
- スパン構成（車線ごと基準・左/右端ライン、セクション引き出し線）
- ライン描画・セクション描画・交角描画・座標テーブル・寸法線(ライン間/セクション間)

## 補足
- 主桁GとセクションSは「スパン内でしか使用できない」独立性
- STORE(GG/SS)で別スパンに保存・参照
