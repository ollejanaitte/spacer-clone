# 優先順位・ロードマップ

## 1. 優先順位の判定基準

- **実務価値**（どの設計ジョブで使うか）: 上部工設計・曲線橋・帳票/図面
- **依存関係**（先行する計算が後続をブロックするか）
- **検証価値**（数値の信頼性・実設計例との突合）
- **工数/リスク**（実装の大きさ）

## 3. ロードマップ（フェーズ案）

### R1（短期）: 数値検証の確立
- F18/F19: 実 JIP-LINER 出力（SRC-004）と実設計例（SRC-005）をゴールデンフィクスチャへ取り込み、一致テストを新設
- 既存の解析参照ゴールデンを「独立検証」として残し、**外部突合を正本**とする二層検証へ

### R2（中期）: 曲線橋のLINER骨格
- F1 拡幅（1次/4次）計算 + 拡幅線からの高さ自動生成（JIP §5.4）
- F8 セクション×主桁の格点モデル / F9 主桁G 円弧・折れ桁
- F13 LDIST 実設計例突合（支間長・格間長・横断間隔長・張出し長）
- F5 ハンチ用G高さ / F11 ハンチ残型 / F10 小標系
- ピア方式拡張（F6）・スパン簡易入力（F7）

### R3（中期〜長期）: 図面・UX・拡張
- 図面: 交角描画（F14）、寸法線規則（F15）、座標テーブル公式化（F16）、プロファイルバンド完成（F17）
- 2Dエディタ MVP（Phase6）: 直線/円/クロソイドのGUI編集・スナップ・オフセット・ピア配置
- 測点有効範囲・接続/分岐（ランプ）モデル

### R4（長期）: 上部工・3D・特殊
- 主桁動径オフセット・放射方向・横桁方向・支承方向（曲線橋幾何）→ Step10 曲線橋
- 床板サーフェス・主桁ソリッド・支承の3D（上部工 Phase2）
- 分岐/Y字橋、APLINE相当、MDSKOUT相当

## 4. 依存関係グラフ

```text
[検証基盤 P1] ← すべての実装が正しさの基準を持つ
    │
[拡幅F1] → [動径オフセット・曲線橋幾何 R4]
    │
[S×G格点F8] → [主桁G F9] → [曲線橋主桁 R4]
    │                └→ [LDIST突合 F13]
    │
[WG高さF5] → [ハンチ残型 F11]
    │
[測点有効範囲F3] → [分岐/接続F2] → [Y字/ランプ R4]
```

## 5. リスク・依存（先行研究と統合）

| リスク | 内容 | 対応 |
|---|---|---|
| 曲線橋の解析要件（曲げねじり・遠心力）未実装 | Scope_of_Work の Step10 は解析/照査/報告/図面が BLOCKED | LINER層は幾何生成に集中、解析は上部工 |
| ハンチ型12はWG/Wの両高さが必要 | 現行 Z Merge は合成1方式 | WG系を別系統で持つ設計 |
| Importer の補間（C1-C17/GE2） | 実PDF値への置換が必要（F19） | 数値の実証性 |
| 2Dエディタと既存図面モデルの整合 | DrawingPrimitive（出力）と要素ハンドル（編集）の2層 | 変換層で接続 |
| 分岐/接続のデータモデルが大きい | active alignment からトポロジー化 | 段階導入（測点範囲→分岐） |

## 6. まとめ

最優先は **「数値検証（外部突合）」と「曲線橋の骨格（拡幅・S×G格点・主桁G）」**。これらは現在の「実装あり（解析参照のみ検証）・型定義のみ」の状態を「実設計と突合された信頼実装」へ引き上げる。
