# ROAD_ORDINANCE_REVERSE_ENGINEERING — 道路構造令 設計ルール抽出

本資料は、道路構造令の解説と運用（令和3年3月）の本文から、X1-P01 で抽出した
設計ルールのサマリである。全項目は `RULE_INVENTORY.csv` に証跡付きで収録。

## 1. 抽出方法

- 情報源: DOC-X0-0145（道路構造令の解説と運用_令和3年3月.pdf, スキャン画像・テキスト層なし）
- 印刷ページ↔PDFページ対応をフッターの限定OCRで構築（PDF78〜260 → 印刷124〜483）
- 対象節の値が載るページのみを限定OCR（全文OCRなし）
- 証跡: source_page（印刷ページ）を全FACTに付与

## 4. 例外・注意（EXCEPTION）

- 緩和区間の省略: 第4種の道路・地形等特別理由（第18条）
- 最小曲線半径の縮小: 最大片勾配10%を付す場合（第15条）
- 設計速度の右欄値: 高速自動車国道第1種第4級を除く（第13条）
- 路肩・中央帯の縮小: 長大区間・高架等（第6条・第13条）
