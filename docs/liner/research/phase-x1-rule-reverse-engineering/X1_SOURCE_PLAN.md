## 2. 道路構造令のページ対応

- 本PDFはスキャン画像（テキスト層なし）。印刷ページ番号とPDFページ番号が異なる。
- X1-P01 冒頭で、Ⅲ-1/2/3 の各節の印刷ページ→PDFページ対応を「フッターの限定OCR」で確定する。
- 全文OCRは行わず、対象節の値が載るページのみ OCR する。

## 3. OCR計画（限定）

- 道路構造令: 対象節の表・数値が載るページのみ（見込み30〜60ページ）
- 道示: X1-P04で必要な章のみ（見込み20ページ程度）
- それ以外（JIP-LINER・実案件・鋼鈑桁橋・APOLLO）: テキスト層ありのためOCR不要

## 4. 証跡の持ち方

- 各ルールに source_asset_id / source_page（印刷ページ）/ source_section / source_item を付与
- 数値は原文の表・条文から FACT として取得。推測は INFERENCE、不足は UNRESOLVED。
