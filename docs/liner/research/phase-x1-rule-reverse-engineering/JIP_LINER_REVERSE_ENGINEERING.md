# JIP_LINER_REVERSE_ENGINEERING — JIP-LINER機能リバースエンジニアリング

JIP-LINER（線形座標計算システム）のマニュアル（DOC-X0-0035, 183頁）から機能を整理し、
道路構造令Rule候補との対応を `STANDARD_TO_LINER_MAPPING.csv` に定義する。

## 1. 基本情報（FACT）

- 製品: JIP-LINER（線形座標計算システム） / JIPテクノサイエンス株式会社 / 令和05年05月
- 出力書式: USERS MANUAL（Windows 11/10）
- 機能区分: 線形計算・ハンチ計算・舗装厚計算・図面作成・格点間距離チェック

## 2. プログラム構成（FACT）

| プログラム | 機能 |
| --- | --- |
| LINER | 線形計算（ラインデータ→測点→高さ→ピア→スパン→出力） |
| HAUNCH | ハンチ計算（計算タイプ1〜17） |
| HOSO | 舗装厚計算（縦断/横断・3点/2点指定） |
| GDRAW | 平面図・座標テーブル作成（自動描画） |
| LDIST | 格点間距離・張り出し長の出力 |
| MDSKOUT | MightyBridge連動用ファイル作成 |
| APLINE | 予備計算 |
| LTOOL | 線形情報出力 |
| GVIEW | 線形一般図作成 |
| FOOTING | フーチング図作成 |
| MDVIEWER | 橋面面積計算・3次元DXF出力等 |
| GCROSS | 標準断面図作成 |

## 3. 制約条件（FACT）

- ライン数100 / 要素数100 / ステーション数50 / 縦断データグループ50 / 横断データグループ50 /
  断面高さデータ数50 / 変更断面数50 / ピア数500 / スパン数90 /
  ライン数＋縦桁G本数100（1スパン当たり）/ 横桁S本数500（1スパン当たり）/ ストアデータ数50 / 折れ点数50

## 4. 線形計算のデータフロー（FACT）

```
ラインデータ（5.2）→ 測点設定（5.3）→ 高さデータ（5.4）
  ├ 縦断勾配（5.4.1）
  ├ 横断勾配（5.4.2）
  └ 断面高さ設定（5.4.3）
→ ピア設定（5.5）→ スパンデータ（5.6）
  ├ 桁設定（5.6.2：縦桁G・横桁S）
  ├ 出力指定（5.6.3）
  └ 座標変換（5.6.4：TRAN）
→ 出力データ（5.7）→ 格点間距離チェック（5.8：格点間距離・張り出し長）
```

### 要素入力（5.2.2）※道路構造令との対応点

- 要素種類: S=直線要素 / R=円要素 / A=クロソイド要素（FACT）
- クロソイド設定例: `A=350.0 R=3000.0`（パラメータAと半径R）（FACT）
- 円の半径の符号: 負=右カーブ / 正=左カーブ（FACT）
- 拡幅タイプ: 空白=平行 / 1=1次拡幅 / 4=4次拡幅（FACT）
- 設定方法: (1)始終点座標とパラメータ (2)延長距離とパラメータ (3)基準要素を平行（拡幅）移動

### ピア設定（5.5）

- ピア記号: 'K'+正整数（例 K10）（FACT）
- 設定方法: 2点を結ぶ / 1点と角度 / 要素変化点 / 測点入力（FACT）
- 角度指定: 方位角 / ラインに対して角度 / 直線に対して角度（FACT）

### 格点間距離（5.8.2）

- 距離の計算方法: セクション上の距離 or セクション上の距離×sin(交角)（FACT）
- 計算ライン（主桁）・計算セクションの指定（FACT）

### 張り出し長（5.8.3）

- 左側ライン・右側ライン・計算セクションを指定して張り出し長を出力（FACT）

## 5. 道路構造令ルールとの対応（要約）

`STANDARD_TO_LINER_MAPPING.csv`（22件）参照。主要な対応:

| 道路構造令 | LINER |
| --- | --- |
| 曲線半径・曲線長・緩和区間 | 要素入力（R要素・A要素・延長距離） |
| 測点（STATION） | 測点設定 |
| 縦断勾配・縦断曲線 | 高さデータ（縦断勾配） |
| 横断勾配・片勾配 | 高さデータ（横断勾配） |
| 車線幅員・拡幅 | 断面形状（幅員・拡幅線） |
| ピア・スパン・桁 | ピア設定・スパンデータ（縦桁G・横桁S） |
| 格点・張り出し | 格点間距離チェック（LDIST） |
| 座標変換 | 座標変換（TRAN） |
| 図面生成 | GDRAW・MDVIEWER（3D DXF） |
