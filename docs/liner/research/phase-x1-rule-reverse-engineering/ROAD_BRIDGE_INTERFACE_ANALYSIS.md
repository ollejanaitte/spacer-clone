# ROAD_BRIDGE_INTERFACE_ANALYSIS — 道路・橋梁インターフェース分析

道路線形（実案件・道路構造令）が橋梁設計データへどのように引き継がれるかを、
鋼鈑桁橋設計計算例（DOC-X0-0001）を中心に分析する。

## 1. 対象事例（FACT）

- 旭高架橋 Aランプ PU15-AR2 上部工（鋼3径間連続少数鈑桁橋）
- 道路規格: A規格 / 設計速度 V=40km/h / 活荷重 B活荷重
- 橋長 134.001m (ACL上) / 桁長 133.151m / 支間 40.201+51.000+40.200m
- 総幅員 8.010m / 有効幅員 7.000m（車道幅）
- 斜角: PU15: ACLに θ=94°14'27" / PR1・PR2・A2: θ=90°
- 平面線形: R=160m（起点側・左回り）〜 R=3000m（終点側・右回り）
- 縦断勾配: i=6.000%（起点下がり）VCL=100, i=0.100%（終点下がり）
- 横断勾配: i=5.000%（左下がり）〜 i=2.000%（右下がり）〜 i=2.958%
- 適用基準: 道路橋示方書・同解説（H29.11）等

## 2. 「道路線形由来」と「構造設計で決まる値」の区別

| 区分 | 項目 | 根拠 |
| --- | --- | --- |
| ROAD_DERIVED（道路線形由来） | 平面線形（R=160/3000）、測点、縦断勾配、横断勾配・片勾配、車道幅員 | 道路の線形が橋梁に引き継がれる |
| INTERFACE（道路↔橋梁の接続） | 斜角（交角）、設計速度・活荷重、張り出し、格点間距離、CAD出力 | 道路・橋梁双方の接続で決まる |
| STRUCTURE_DEFINED（構造設計で決まる） | 橋長・桁長・支間長、主桁構成、格点座標・部材番号、桁間隔 | 上部工の構造設計で決定 |

## 3. 主要な引き継ぎ（ROAD_TO_BRIDGE_MAPPING.csv 14件）

- 道路の平面線形（曲線R）→ 曲線橋の線形（R=160のランプ橋）
- 縦断勾配（6%）→ 橋梁の縦断
- 横断勾配・片勾配 → 橋梁の横断勾配（5%→2%）
- 交角 → 橋梁の斜角（94°14'27"）
- 車道幅員 → 橋梁の有効幅員（7.0m）
- 測点 → 支点位置（ACL上）

## 4. LINER・APOLLOとの関係

- JIP-LINER（DOC-X0-0035）: 線形・測点・ピア・スパン・桁（縦桁G/横桁S）・格点間距離・張り出し長を算出 → 橋梁モデルの入力
- APOLLO SuperDesigner/SuperDrawing（DOC-X0-0091）: 線形計算→自動設計→計算書→AutoCADデータ生成（DXF）
- 道路構造令ルール（RO-xxx）: 道路の基準値は橋梁の設計条件（幅員・斜角・線形）の前提

## 5. UNRESOLVED

- 張り出し長の具体的な値（橋梁側）は要確認
- 道示Ⅰの荷重・照査式のページ番号は道示のOCR後に確定
- 少数主桁の桁間隔（2主桁）の具体的寸法は一般図で確認必要
