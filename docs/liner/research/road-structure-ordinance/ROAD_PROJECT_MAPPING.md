## 3. LINER側の既存データモデル（docs/road/design/domain_model.md）

- `LinerProject` : ルート、メタデータ
- `HorizontalAlignment` / `HorizontalSegment`（straight / circular arc / clothoid）
- `VerticalAlignment` / `VerticalSegment`（grade line / parabolic vertical curve）
- `StationEquation` : 測点不連続（実案件の BP・IC測点表と対応）
- `CrossSectionTemplate` : 車線幅・オフセット・構造参照
- `Span` / `Pier` / `GenerationSettings`

上記に対し、道路構造令の基準値（車線幅員・路肩幅・最小R・片勾配・縦断勾配等）を
**照査ルール（Rule Engine）**として追加することで、実案件の入力値 → 照査 → 警告 の
パイプラインを構成できる見込みである。
