# R1_PLAN

- **適用範囲**: spacer-clone 上で計画する「R1 数値検証基盤」
- **種別**: 実装前計画（この文書のみ作成。実装は行わない）
- **基準**: 下記参照（spacer-clone 作業中 worktree の読み取り値）

## 0. 背景・目的

上流ロードマップ（roadmap.md）および差分監査（gap_matrix.csv）より、最優先 P1 は
「数値検証（外部突合）」です。現行のゴールデンテストは解析参照（Simpson 等）のみであり、
「実 JIP-LINER 出力」と「実設計計算例」との突合が存在しません（GAP-1000, GAP-1001, GAP-1002）。

本 R1 計画は、**実装に先立つ設計/手順/合意事項**を文書化し、実装フェーズの指針とします。

## 1. 対象 GAP と方針

| GAP | 現状 | R1 目標 |
|---|---|---|
| GAP-1000 | ゴールデンが解析参照のみ | 実 JIP 出力（SRC-004）・実設計例（SRC-005）を「正本」とする一致テストを新設 |
| GAP-1001 | 描画ゴールデンが自己参照 | 外部帳票（実設計図面）との突合を正本化 |
| GAP-1002 | Importer の C1-C17/GE2 が interpolated | PDF 実値へ置換 |

## 2. 二層検証設計（提案）

```text
Layer 1: 解析参照（既存）…… Simpson / 数式による閉形式計算（独立検証として残す）
Layer 2: 外部突合（正本）…… JIP-LINER 実出力（SRC-004）・実設計計算例（SRC-005）と一致
```

- Layer 1 は「自己一貫性」の検証
- Layer 2 は「実務突合」の検証。**Layer 2 を合否の正本**とする。

## 3. 作業フロ（実装フェーズでの手順案）

1. 対象機能（F18/F19）を識別（※R1計画内では対象ソースは read のみ）
2. ゴールデンフィクスチャの由来欄を「外部突合」に更新
3. 一致テスト（fixture-driven）を新設
4. Layer 1 を独立に残置
5. Importer の補間値を PDF 実値に置換（GAP-1002）
6. 実行・判定（CI 化は Roadmap R2 以降）

## 4. 判定基準（一致テスト用・提案）

- 許容誤差: 座標軸 10^(-6) m、角度 10^(-9) rad（設計精度ポリシーの既定値。実装改訂で調整）
- 一致判定: 全セル hit; 1件でも不一致なら FAIL
- 差分レポート: 機能名 / 入力ハッシュ / 期待値 / 実測値 / 相対誤差

## 5. 出張点と対応

| 出張点 | 対応案 |
|---|---|
| 実設計例が PDF で機器取得不可能な項目 | PDF からの手入力 / 人手読み取りを明示記録（出張記録に残す） |
| JIP の内部仕様不明（丸め/桁落ち） | SRC-001 マニュアル P183 参照。差が残る場合は tolerance を設計決定として明示 |
| Layer 1 と Layer 2 の差異 | Layer 2 が正本。Layer 1 は情報用。差異は記録し判断材料にする |
| Importer 補間値（C1-C17/GE2） | PDF 実値に置換し、補間であることをマーク解除 |
