## 3. 実行手順（実装フェーズでの手順案）

1. 対象機能のゴールデンフィクスチャ由来を LAYER2 に更新
2. テスト実装（fixture-driven）
3. 実行 → 期待値との差分
4. 差分の場合は tolerance 調整 or 実値での RDF 精確化（精確記録）
5. 全 PASS で R1 完了

## 4. 判定規約

- 全 TC が expected と一致（許容誤差内）→ PASS
- 1 件でも不一致 → FAIL（差分レポート出力）
- Importer は置換完了を条件（interpolated マーク解除）

## 5. 環境

- 実行: ローカル（spacer-clone の既存テスト基盤に準拠。実装時）
- CI: 既定では組み込まない（CI 化は R2 で合意）

## 6. 終了条件

- TC-001〜TC-012 が全 PASS
- GAP-1000 / 1001 / 1002 の状態を「解消(外部突合)」へ更新
- R1 完了報告書をローカル r1-planning/ に作成
