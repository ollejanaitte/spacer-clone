# R1_ACCEPTANCE_CRITERIA

- **適用範囲**: spacer-clone 上で計画する「R1 数値検証基盤」の受入基準（実装前・計画用）

## 1. 受入条件（Must）

1. **外部突合が正本**であること（LAYER2_EXTERNAL が合否の最上位）。
2. **GAP-1000/GAP-1001/GAP-1002 の解消**が可能であること（テスト項目で確認可能な形）。
3. **二層検証**（LAYER1 解析参照 + LAYER2 外部突合）が共存し、LAYER2 が正本と明確であること。
4. **由来（provenance）付きゴールデン**であること（source / reference / input_hash / tolerance を持つ）。
5. **破壊的変更なし**で既存テスト基盤に追加（リグレッション回避）。
6. **あいまいさ排除**: 補間値（C1-C17/GE2）の置換基準が明示されていること。
7. **不変性（トラッキング）**: 差分の記録・許容誤差の根拠が文書化されていること。

## 2. 完了（exit criteria）

| 項目 | 完了条件 |
|---|---|
| テスト新設 | TC-001〜TC-012（外部突合）が PASS |
| 置換 | Importer の補間値（C1-C17/GE2）が実値に置換済み |
| 二層 | LAYER1 / LAYER2 の区別が metadata で明確 |
| 文書 | R1 完了報告が r1-planning に保存 |

## 3. 禁止事項

- 実装・Git・GitHub 操作（本計画フェーズ）
- spacer-clone への直接変更

## 4. 署名

- 計画時点の決定として本文書を確定
- 実装フェーズのための受入条件として利用できる
