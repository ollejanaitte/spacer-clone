# R1_VERIFICATION_STRATEGY

- **適用範囲**: spacer-clone 上で計画する「R1 数値検証基盤」の検証戦略（実装前・計画用）

## 1. 二層検証全体

| 層 | 用途 | 正本? | 内容 |
|---|---|---|---|
| LAYER1_ANALYTIC | 独立検証（解析参照） | 否 | Simpson 等の閉形式計算・自己一貫性 |
| LAYER2_EXTERNAL | 正本（外部突合） | **はい** | 実 JIP 出力（SRC-004）・実設計例（SRC-005）・実帳票 |

- 合否は LAYER2 基準。
- LAYER1 は「理論的整合」のバックアップとして維持。

## 2. 検証ステップ（実装フェーズの手順案）

1. 対象機能の実出力を取得
2. LAYER2 期待値（外部値）と照合
3. tolerance 内で一致 → PASS
4. 不一致 → 出張記録（PDF 由来桁・丸め・変換桁）に記録し、対処（実値校正 or tolerance 決定）
5. Importer 補間値は PDF 実値へ置換（GAP-1002）

## 3. 誤差管理

| 要因 | 方針 |
|---|---|
| JIP 内部仕様不明（丸め/桁落ち） | SRC-001（P183）参照。残差は tolerance を設計値として明示 |
| PDF 由来 手入力 | 出張記録を残す。tolerance 決定の根拠にする |
| Layer1/Layer2 差異 | 差異は記録し、LAYER2 を正本と判断 |

## 4. 自動化タイミング

- R1 は「一致テスト」の構築のみ（ローカル実行）
- CI への組込み・全回帰は R2 以降で合意

## 5. 報告

- 各フィーチャの PASS/FAIL と「由来」をフィクスチャ metadata に記録
- R1 完了報告（r1-planning/）を最終成果物とする
