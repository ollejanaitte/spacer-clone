13. Sol利用
================================================================
1回実施（codex exec・gpt-5.6-sol）。指摘5件を反映:
1. inspect/import の同期I/F → async化（V1→V2 migration / canonicalHash が非同期のため）
2. envelope checksum は canonicalHash（canonicalize+sha256）であり単純sha256でない → 文書修正
3. V1 existingConditions は {id, assetRef} 参照 → asset JSON の checksum 検証＋解決を明記
4. 軸規約の誤ラベル（x=easting/y=northing を x-along/y-transverse と宣言）→ terrainDocument
   mirror を Lane T 確定まで保留・raw payload + metadata のみ保持に変更
5. layerMappings / settings が mapping・未対応一覧に無い → metadata へ保持（deferred）で対応
反映後: 契約テスト26件・typecheck・build 再PASS。
（初回はCLI v0.131.0がgpt-5.6-sol非対応で失敗。codex update後 v0.147.0 で成功。）
