====================================================
4. V-2 統合 Layer Contract (概要)
====================================================

実装: frontend/src/viewer/layers/layerContract.ts (+ renderCoordinate.ts)
文書: docs/development/unified-3d-viewer-layer-contract.md

- UnifiedViewerModel = { contractVersion, id, worldBasis, renderTransform, layers[], selection }
- 6種 ViewerLayer: terrain / road / superstructure / bearing / substructure / existingConditions
- 各 Layer 共通フィールド: id / kind / visible / selectable / bounds /
  data / metadata / properties / status (loading|ready|empty|error) / source (owner Lane)
- 座標系: canonical 世界座標 (X=沿, Y=横, Z=標高, unit=m, 右手系) を基準にし、
  Viewer は単一 renderTransform (既定 = domainToThree 規約) のみを持つ。
- CRS 変換は Viewer 内に実装しない (WorldBasis に identifier を保持するのみ, Lane T 境界)。
- ProjectModel を描画 I/F にしない (adapter / render model を挟む) ことを契約で明文化。
