# Phase C1 P01 橋台・橋脚・基礎形式調査＋形式Freeze

## 1. 調査目的

一般的な橋台・橋脚・基礎形式を調査し、Phase C1 で3D生成およびLINER平面図表示まで対応する形式を確定する。

---

## 2. 橋台形式（Abutment Types）

### 2.1 逆T式橋台（Inverted-T Abutment）← 現在対応済み

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 背面壁（backwall）が T 字の逆形状。底版（フーチング）上に垂直壁、壁頂に支承座。 |
| **主要構成部材** | 壁（backwall）、左右翼壁（wing wall）、フーチング、杭基礎（任意）、支承座 |
| **3Dパラメータ** | 壁高×厚×幅、天端高、翼壁長×高×厚、フーチング長×幅×厚、杭径×長×本数 |
| **2D平面図形状** | 壁矩形（橋軸直角方向に長い）、左右翼壁矩形（斜めまたは直角）、フーチング矩形 |
| **生成難易度** | ★☆☆☆☆（低い） |
| **C1判定** | **C1_IMPLEMENT**（現在対応済み、継続） |

### 2.2 重力式橋台（Gravity Abutment）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | コンクリートの重量で土圧に抵抗。台形断面。壁体積が大きく、材料費は高いが鉄筋不要。 |
| **主要構成部材** | 壁体（前面勾配あり）、フーチング、支承座 |
| **3Dパラメータ** | 底面幅×天端幅×高さ×橋軸直角幅、前面勾配、フーチング寸法 |
| **2D平面図形状** | 台形の投影。天端矩形と底面矩形の合成。 |
| **生成難易度** | ★★★☆☆（勾配付き壁の3D生成が必要） |
| **C1判定** | **FUTURE**（勾配表現が追加開発必要） |

### 2.3 箱式橋台（Box Abutment / U形橋台）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 前面壁＋側壁＋底版で箱型を形成。内部に裏込め土を入れる。 |
| **主要構成部材** | 前面壁、左右側壁、底版、支承座 |
| **3Dパラメータ** | 各壁の高×厚×幅、底版寸法、内部空間（中空） |
| **2D平面図形状** | コの字型（前面壁＋左右側壁）、底版矩形 |
| **生成難易度** | ★★★☆☆（中空表現が必要） |
| **C1判定** | **FUTURE**（UIの複雑度が高い） |

### 2.4 ラーメン式橋台（Frame Abutment / 逆L式）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 壁＋底版がラーメン構造。逆T式に似るが、壁と底版の接合部が剛結構造。 |
| **主要構成部材** | 壁、底版、支承座。翼壁は別途。 |
| **3Dパラメータ** | 逆T式とほぼ同一。接合部のハンチ有無は追加パラメータ。 |
| **2D平面図形状** | 逆T式と同様（壁矩形＋フーチング矩形） |
| **生成難易度** | ★★☆☆☆（逆T式の拡張で対応可能） |
| **C1判定** | **C1_IMPLEMENT**（逆T式と統合して扱う） |

### 2.5 盛りこぼし橋台（Backfill Abutment / もたれ式）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 壁が背面側に傾斜（もたれ）。土圧で安定。 |
| **主要構成部材** | 傾斜壁、フーチング |
| **3Dパラメータ** | 傾斜角、壁高×厚×幅、フーチング寸法 |
| **2D平面図形状** | 傾斜壁の投影は通常の矩形と変わらない（上面視） |
| **生成難易度** | ★★★☆☆（傾斜角パラメータ追加） |
| **C1判定** | **FUTURE**（特殊形状、需要限定的） |

### 2.6 橋台形式 Freeze 判定

| 形式 | C1判定 | 理由 |
|------|--------|------|
| 逆T式橋台 | **C1_IMPLEMENT** | 現在対応済み。継続。 |
| ラーメン式橋台 | **C1_IMPLEMENT** | 逆T式と同形状。formType 追加のみ。 |
| 重力式橋台 | FUTURE | 勾配付き壁の生成が必要。 |
| 箱式橋台 | FUTURE | 中空＋コの字形状でUI複雑。 |
| 盛りこぼし橋台 | FUTURE | 特殊形状。需要限定的。 |

## 3. 橋脚形式（Pier Types）

### 3.1 RC張出し式単柱矩形橋脚 ← 現在対応済み

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 1本の矩形柱＋上部に張出し梁（キャップ）。橋軸直角方向に張出す。 |
| **主要構成部材** | 柱（矩形断面）、キャップ（張出梁）、フーチング、杭基礎（任意）、支承座 |
| **3Dパラメータ** | 柱幅×奥行×高さ、キャップ幅×高×奥行×張出L/R、フーチング長×幅×厚、杭径×長×本数 |
| **2D平面図形状** | 柱矩形、キャップ矩形（張出含む）、フーチング矩形、杭配置（十字マーカー） |
| **生成難易度** | ★☆☆☆☆（低い） |
| **C1判定** | **C1_IMPLEMENT**（現在対応済み、継続） |

### 3.2 壁式橋脚（Wall-Type Pier）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 橋軸直角方向に長い壁状の柱。単柱に比べ橋軸直角方向の幅が大きい。 |
| **主要構成部材** | 壁（薄肉矩形断面）、キャップ、フーチング、杭基礎 |
| **3Dパラメータ** | 壁幅×厚×高さ、キャップ寸法、フーチング寸法 |
| **2D平面図形状** | 壁矩形（橋軸直角方向に長い）、キャップ矩形、フーチング矩形 |
| **生成難易度** | ★☆☆☆☆（単柱矩形の拡張。width/depth の比率変更のみ） |
| **C1判定** | **C1_IMPLEMENT**（単柱矩形と統合。formType の追加のみ） |

### 3.3 門型橋脚（Portal Frame Pier / ラーメン橋脚）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 2本の柱＋上部横梁で門型を形成。橋軸直角方向に広がる。都市高速・高架橋で多用。 |
| **主要構成部材** | 左右柱（2本）、横梁（キャップ兼用）、フーチング（左右独立または一体）、杭基礎、支承座 |
| **3Dパラメータ** | 柱1本あたり幅×奥行×高さ、柱間隔（芯々）、横梁幅×高×奥行、左右フーチング各寸法 |
| **2D平面図形状** | 2本の柱矩形＋横梁矩形＋フーチング矩形（左右独立または一体） |
| **生成難易度** | ★★☆☆☆（2本柱の配置＋横梁結合。データモデルの拡張が必要） |
| **C1判定** | **C1_IMPLEMENT**（Phase C1 で対応必須。要求に明記あり） |

**門型橋脚の3D生成に必要なデータモデル拡張：**
```typescript
// 現在の model.ts の Pier は単柱のみ想定
// 門型対応の拡張案：
interface PierColumn {
  id: string;
  width: number;    // 橋軸直角幅
  depth: number;    // 橋軸方向奥行
  height: number;
  position?: {      // 追加：門型の場合の柱位置（省略時は中心）
    transverseOffset: number;  // 橋軸直角方向オフセット
  };
}

interface PierCap {
  // 現状維持（門型では横梁として機能）
  // 門型の場合、横梁は柱間を橋軸直角方向に架ける
  spanDirection: "longitudinal" | "transverse";  // 追加：梁の架設方向
}
```

### 3.4 RCラーメン式橋脚（RC Rigid-Frame Pier）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 複数柱＋梁でラーメン構造。門型の拡張（3本柱以上）。 |
| **主要構成部材** | 3本以上の柱、上下横梁、フーチング |
| **3Dパラメータ** | 柱配置（本数・間隔）、各柱断面、横梁断面 |
| **2D平面図形状** | 複数柱矩形＋横梁矩形 |
| **生成難易度** | ★★★☆☆（柱配列のパラメータ化が必要） |
| **C1判定** | **FUTURE**（門型で十分。3本柱以上はデータモデル拡張大） |

### 3.5 中空式橋脚（Hollow-Section Pier）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | 柱断面が中空（矩形中空）。高橋脚で使用。 |
| **主要構成部材** | 中空柱（肉厚壁）、キャップ、フーチング |
| **3Dパラメータ** | 柱外形（幅×奥行）、肉厚、高さ |
| **2D平面図形状** | 単柱矩形と同一（上面視では中空は見えない） |
| **生成難易度** | ★★★☆☆（中空断面の3D生成が必要） |
| **C1判定** | **FUTURE**（外形は単柱矩形で代用可能。中空表現は精度向上フェーズ） |

### 3.6 橋脚形式 Freeze 判定

| 形式 | C1判定 | 理由 |
|------|--------|------|
| RC張出し式単柱矩形橋脚 | **C1_IMPLEMENT** | 現在対応済み。継続。 |
| 壁式橋脚 | **C1_IMPLEMENT** | 単柱矩形の拡張。パラメータ範囲拡大のみ。 |
| 門型橋脚 | **C1_IMPLEMENT** | **Phase C1 で必須対応。** データモデル拡張が必要。 |
| RCラーメン式橋脚 | FUTURE | 門型の拡張。C1 後。 |
| 中空式橋脚 | FUTURE | 外形は単柱で代用可。C1 後。 |

## 4. 基礎形式（Foundation Types）

### 4.1 直接基礎（Spread Foundation）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | フーチングのみ（杭なし）。支持地盤が浅い場合に使用。 |
| **主要構成部材** | フーチング（矩形） |
| **3Dパラメータ** | フーチング長×幅×厚、天端高 |
| **2D平面図形状** | フーチング矩形 |
| **生成難易度** | ★☆☆☆☆（フーチングのみ。杭あり/なしの分岐） |
| **C1判定** | **C1_IMPLEMENT** |

### 4.2 場所打ち杭基礎（Bored Pile Foundation）← 現在対応済み

| 項目 | 内容 |
|------|------|
| **一般的な外形** | フーチング＋場所打ち杭（現場掘削・コンクリート打設）。 |
| **主要構成部材** | フーチング（矩形）、杭（円柱、矩形グリッド配置） |
| **3Dパラメータ** | フーチング長×幅×厚、杭径×長×本数×間隔 |
| **2D平面図形状** | フーチング矩形＋杭位置（十字マーカー） |
| **生成難易度** | ★☆☆☆☆（現在対応済み） |
| **C1判定** | **C1_IMPLEMENT**（現在対応済み、継続） |

### 4.3 鋼管杭基礎（Steel Pipe Pile Foundation）

| 項目 | 内容 |
|------|------|
| **一般的な外形** | フーチング＋鋼管杭。場所打ち杭と類似だが杭材質・打設方法が異なる。 |
| **主要構成部材** | フーチング（矩形）、鋼管杭（円筒） |
| **3Dパラメータ** | 場所打ち杭と同一。`pileType` の違いのみ。 |
| **2D平面図形状** | 場所打ち杭と同一 |
| **生成難易度** | ★☆☆☆☆（pileType 列挙値追加のみ） |
| **C1判定** | **C1_IMPLEMENT**（pileType に `steel_pipe` 追加） |

### 4.4 ニューマチックケーソン基礎（Pneumatic Caisson Foundation）

| **C1判定** | **FUTURE**（特殊基礎。C1範囲外） |

## 5. 現在実装との比較

### 5.1 現在対応している形式

| 区分 | 形式 | 対応度 |
|------|------|--------|
| 橋台 | 逆T式（`inverted_t`） | 完全対応 |
| 橋脚 | 単柱矩形（`single_column_rect`） | 完全対応 |
| 基礎 | フーチング（矩形） | 完全対応 |
| 基礎 | 場所打ち杭（`bored_pile`） | 完全対応 |

### 5.2 model.ts の制約

| 制約 | 詳細 |
|------|------|
| `PierFormType` | `"single_column_rect"` のみ。門型・壁式を追加するには拡張が必要。 |
| `AbutmentFormType` | `"inverted_t"` のみ。ラーメン式を追加するには拡張が必要。 |
| `PileType` | `"bored_pile"` のみ。`"steel_pipe"` 追加が必要。 |
| `PierColumn` | 単柱のみ想定。門型では2本の柱位置指定が必要。 |
| `PierCap` | 張出梁のみ想定。門型の横梁では `spanDirection` 指定が必要。 |
| `Footing` | 単一フーチングのみ。門型では左右独立フーチングも想定。 |
| `Support` | 1 Support = 1 Pier または 1 Abutment。門型も1 Support で表現可能。 |

### 5.3 geometry.ts の制約

| 制約 | 詳細 |
|------|------|
| `buildPier()` | 単柱のみ。門型の2本柱＋横梁は未対応。 |
| `buildAbutment()` | 逆T式のみ。ラーメン式は壁とフーチングの一体化表現が必要。 |
| `buildPiles()` | 矩形グリッド配置のみ。千鳥配置・不等間隔は未対応。 |
| 門型 | `buildPortalPier()` 相当の新規関数が必要。 |
| 壁式 | 単柱の幅を拡大すればgeometry的には対応可能。 |

### 5.4 LINER 平面図投影時に不足する情報

| 不足 | 詳細 |
|------|------|
| 門型の柱位置 | 現在の平面図投影では単柱の中心のみ。門型では2本の柱位置と横梁範囲が必要。 |
| 翼壁の角度 | 逆T式の翼壁は直角（橋軸方向）。実際の設計では斜め配置も多い。 |
| 杭の千鳥配置 | 現在は矩形グリッドのみ。設計では千鳥配置も一般的。 |
