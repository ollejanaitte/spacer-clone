# スコープ定義（Scope）

区分:
- PROPOSED : 今回提案する事項
- UNRESOLVED : 未解決

## 1. 初期スコープ（今回対象）

### 1.1 対象構造
1. 単柱式RC橋脚（矩形柱）
2. 張出式橋脚梁
3. 支承座
4. 矩形フーチング
5. 場所打ち杭
6. 逆T式橋台の簡易外形
7. 翼壁の簡易外形
8. 上部工簡易外形
9. 地盤面の簡易表示

### 1.2 機能
- 新規プロジェクト作成・名称入力
- 支点ID・座標X/Y/Z入力
- 橋軸方向・橋軸直角・鉛直方向・斜角入力
- 支承位置・数・高入力
- 桁下高入力
- 橋脚形式選択（単柱矩形）
- 柱幅・柱奥行・柱高入力
- 梁幅・梁高・梁奥行入力
- フーチング寸法入力
- 杭径・杭長・杭本数・杭間隔入力
- 橋台寸法入力
- パラメータ変更時の3D再生成
- JSON保存・再読込み
- 入力値検証
- 概算コンクリート体積・概算杭延長
- glTF/GLB/STL/OBJ等の出力方式比較
- 上部工簡易モデルとの重ね合わせ
- 安定した要素ID付与
- 未対応条件のfail-closed

## 2. 非スコープ（今回対象外）

- 道路橋示方書に基づく正式照査
- RC断面の正式な耐荷性能照査
- せん断照査・曲げ照査・疲労照査
- レベル1・レベル2地震時の正式設計
- 動的解析・非線形解析
- 塑性ヒンジ照査・変形性能照査
- 地震時保有水平耐力法
- 基礎の正式支持力照査
- 杭の正式設計
- 地盤ばねの正式算定
- 液状化判定・地盤応答解析
- 配筋自動設計・配筋図自動生成
- 正式な数量計算・設計計算書
- 実務利用可能との表示
- 上部工本体への実装
- spacer-cloneへのコード移植
- GitHubへの成果反映

NUMERIC_DESIGN_AUTHORIZATION: NOT_GRANTED
PRODUCTION_USE_AUTHORIZATION: NOT_GRANTED
CALCULATION_STATUS: RESEARCH_ONLY
RESULT_LABEL: 参考値・未検証・実務使用不可

## 3. 反力データの扱い

- 反力なし: 3Dモデリング使用可、概算数量使用可、反力依存計算は無効、正式照査は常に無効
- 反力あり: 表示用のみ。反力計算・照査はしない

## 4. 対象外の明確化

- 上部工の実モデルは対象外（簡易外形のみ）
- 実地盤・地質・液状化は対象外
- 施工性・施工計画は対象外
- 数量集計の実務精度は対象外（幾何概算）

## 5. 今後の拡張余地（次段階候補）

- 複数柱・多柱式橋脚
- RC橋台の詳細化
- 直接基礎・ケーソン基礎
- 杭配置パターン生成
- 配筋数量の概算
- 上部工からの反力インポート
- 2D図面（一般図）出力
- 耐震設計（レベル1・2）は将来の別ステージ
