# 要求整理（Requirements）

区分:
- SOURCE_DERIVED : 資料から読み取った事項
- PROPOSED : 今回提案する事項
- INFERENCE : 資料・既存コードを基にした推論
- UNRESOLVED : 未解決

## 1. 目的

下部工計画・3Dモデリングツール（仮称）は、正式な下部工設計ソフトではなく、
- 下部工の計画段階での3Dイメージ
- パラメトリック形状生成
- 上部工との疎結合データ連携
- 概算数量の把握
をローカルで行う検証ツール。

SOURCE_DERIVED + PROPOSED。

## 2. 利用者

- 計画・概算設計を担当する橋梁技術者
- 3Dモデル検討担当
- プログラム関係者（デモ・検証）

## 3. ユースケース（UC）

| ID | 名称 | 説明 |
|---|---|---|
| UC-01 | 新規プロジェクト作成 | プロジェクト名・支点ID・座標・斜角入力 |
| UC-02 | 構造形式選択 | 橋脚・橋台・基礎形式選択 |
| UC-03 | 寸法入力と3D再生成 | 柱/梁/フーチング/杭寸法を変えて即再生成 |
| UC-04 | 上部工簡易外形との重ね合わせ | 上部工の箱モデルを表示 |
| UC-05 | JSON保存・再読込み | 同一データの復元 |
| UC-06 | 入力検証 | 負値/0/形式エラー表示 |
| UC-07 | 概算数量表示 | コンクリート体積・杭延長 |
| UC-08 | 3Dエクスポート | glTF/GLB/STL等の比較・出力 |
| UC-09 | 部材選択 | 3D上の部材クリックでID表示 |
| UC-10 | 反力データ取込（任意） | 上部工から反力JSONを受けて表示（反力計算はしない） |

## 6. 入力/出力

### 6.1 入力
プロジェクト情報、支点、構造形式、寸法、支承、上部工簡易外形、反力（任意）

### 6.2 出力
3D表示、概算数量、JSON保存、3Dエクスポート（glTF/GLB/STL/OBJ比較）

## 7. 前提条件

- 対象は計画段階。実務設計の照査・計算は含まない。
- 単位系は SI（m, kN）。単位不明は拒否。
- 座標系は右手系 Z-up（x-longitudinal-y-transverse-z-up）を基本とする。

## 8. 制約

- 正式照査しない。数値は参考値・未検証・実務使用不可。
- 商用ソフトの画面・ソース複製禁止。
- 未対応形式は fail-closed。

## 9. 未解決事項

UNRESOLVED:
- 桁下高の起点（支承天端 or 桁下端）の定義
- 斜角の正負の現場定義の揺れ
- 上部工側から反力が渡る場合の標準的な形式
