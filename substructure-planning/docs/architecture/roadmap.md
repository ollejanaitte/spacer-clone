# 実装ロードマップ（Roadmap）

区分: PROPOSED

## 1. MVP（最小製品候補）現段階 = 本検証

下部工計画・3Dモデリングツールの第1版として本LABで検証するもの。

スコープ:
- 単柱式RC橋脚（矩形柱）
- 張出梁・支承座
- 矩形フーチング
- 場所打ち杭
- 逆T橋台・翼壁・上部工・地盤面の簡易外形
- JSON入出力・入力検証・概算数量・3D再生成・エクスポート比較

MVP 判定ゲート:
- 単柱橋脚の3D再生成が動く
- JSON 保存/再読込みが一致する
- 概算数量が表示される
- 入力検証が働く
- spacer-clone/gitHubへの影響ゼロ

## 2. 次段階（Phase B）

- 多柱式・門型橋脚
- 橋台の詳細化（U型・逆T型の選択）
- 杭配置パターン（不等間隔・段数）
- 上部工からの反力インポート（support-interface.json）
- STL/glTF/GLB 出力の正式化
- 数量集計の詳細化（鉄筋概算）

## 3. 将来の概略設計（Phase C）

- 下部工と上部工の一体連携
- 温度・乾燥収縮
- 耐震（レベル1）概略照査
- 地盤モデルと基礎反力照査（簡易）

## 4. 将来の詳細設計（Phase D）

- 道路橋示方書に基づく正式照査
- 曲げ・せん断・変形照査
- 配筋設計
- 詳細計算書生成

※ Phase D は今回の非スコープ。NUMERIC_DESIGN_AUTHORIZATION NOT_GRANTED を維持。

## 5. 必要な検証資料（将来）

- 下部工の設計計算書例（橋脚・橋台・基礎）
- 下部工の図面例
- 支持力・杭の検算
- 支承の標準品目

## 6. ロードマップ表

```text
[今] MVP（本LAB検証） → Phase B 拡張 → Phase C 概略 → Phase D 詳細
  単柱・矩形              多柱・橋台     設計照査(概略)   示方書照査
  JSON/3D/数量            反力入力       一体連携          配筋・計算書
```

## 7. リスクと克服

- データモデルの過剰化 → MVPで最小化
- 反力分類 不一致 → 交換スキーマで分類を明示
- 座標系の誤解 → 検証テストで確認
