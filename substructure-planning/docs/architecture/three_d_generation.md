# 3D生成方式（Three-Dimensional Generation）

区分:
- PROPOSED : 今回提案する事項
- EXISTING_CODE_DERIVED : spacer-clone から読み取った事項
- INFERENCE : 推論

## 1. 方式概要

パラメトリックモデルを、部材ごとのプリミティブ（Box / Cylinder）の合成として生成する。
寸法パラメータ → ジオメトリ → Three.js メッシュ という一方向の変換。

- 安定IDを node.name に付与し、選択（raycast）でID表示
- パラメータ変更時はジオメトリを再構築（dispose + rebuild または Shape/Box更新）
- 全体を一つの Group にまとめ、回転・移動を適用

## 2. ジオメトリ生成

### 2.1 部材とプリミティブ

| 部材 | プリミティブ | 位置 |
|---|---|---|
| 支承座 | Box | 梁天端上 |
| 支承 | Box | 支承座上 |
| 橋脚梁（張出） | Box（または 台形・ハンチ） | 柱天端 |
| 柱 | Box | フーチング上面から梁下面 |
| フーチング | Box | 地盤面下 |
| 杭 | Cylinder | フーチング下面から杭長 |
| 橋台（逆T） | Box合成 | 支点位置 |
| 翼壁 | Box | 橋台側面 |
| 上部工簡易外形 | Box（橋軸方向に長い） | 支承上 |

### 2.2 梁・支承座の形状

- 梁は張出式のため、柱芯から左右に張り出す。梁幅・梁高・梁奥行で定義。
- 支承座は梁上面に置く小さい Box。
- 簡単のためハンチは初期は省略し、オプションで表現（INFERENCE: 図面例ではハンチ表現あり、
  初期プロトタイプでは省略し安定動作を優先）。

### 2.3 柱

- 単柱矩形。柱幅（橋軸直角）、柱奥行（橋軸）、柱高。
- 位置はフーチング上面から梁下面まで。

### 2.4 杭

- 場所打ち杭。杭径・杭長・本数・間隔。
- フーチング下面から杭長下に生成。間隔から等間隔配置。
- 群として PileGroup でまとめる。

### 2.5 橋台（逆T式簡易外形）

- 背壁・底版・天端で構成する簡易 Box 群。
- 橋軸方向に壁、橋軸直角に長い底版。

### 2.6 上部工簡易外形

- 支点間を覆う橋軸方向の長い Box（SuperstructureEnvelope）。
- 支承高・桁下高・床版厚に基づき配置。

### 2.7 地盤面

- 半透明の平面（PlaneGeometry）を地盤標高に配置。

## 3. 再生成戦略

- 全ジオメトリを毎回破棄して再構築する方式（シンプル、初期実装）
- または、寸法変更した部材だけ更新する方式（将来）
- 安定IDは保持し、name は変更しない

PROPOSED: 初期は全再構築 + 一部材のパラメータ変更でもID維持。性能は問題ない規模。

## 4. 座標変換

- 橋軸方向（longitudinalAxis）と斜角（skewAngle）でグループを回転。
- 支点座標でグループを並進。
- 各下部工は support.position に配置される。

## 5. エクスポート（比較）

| 形式 | 部材ID保持 | メタデータ | 単位 | 座標 | 判定 |
|---|---|---|---|---|---|
| glTF/GLB | node.name / customProperties | 可 | 可（meter） | 可（右手系、Z-upも可） | 第一候補 |
| STL | 不可（三角メッシュのみ） | 不可 | 不可 | 可（頂点座標のみ） | 参考・数量確認用 |
| OBJ | 不可（nameはObject可） | 限定 | 不可 | 可 | 必要性低 |

EXISTING_CODE_DERIVED: spacer-clone では Binary STL を @jscad/stl-serializer で出力している。

PROPOSED:
- glTF/GLB を推奨（メタデータ・単位・座標保持）
- STL はメッシュ確認用
- OBJ は他ソフト取り込み用の選択肢として実装可

## 6. パフォーマンス・制限

- 初期は単柱・矩形のみ。曲線・斜角大は直線近似。
- 部材数が少ないため、全再構築で十分。

## 7. 検証テスト

- 柱寸法変更時の再生成
- 梁・フーチング・杭径・本数・間隔変更時の再生成
- 橋軸方向変更時の回転
- 斜角変更時の回転
- 支点座標変更時の移動
- 複数支承配置
- 上部工簡易外形との接続
- 保存後の再読込み一致
